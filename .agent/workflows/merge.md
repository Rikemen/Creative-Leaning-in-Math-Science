# Branch Merge & Cleanup Planner (日本語)

**トリガー:** `/merge`

**説明:**
開発完了した機能ブランチを、GitHubのプルリクエスト（PR）を経由せずに**ローカルで直接 `main` へマージ**し、不要なブランチをクリーンアップするためのコマンドを立案・提示します。
1人開発でレビューが不要な場合や、極めて軽微な修正を即座に反映したい場合のショートカットとして使用します。
※チーム開発等でPRによるレビューやCIを通したい場合は、`/make-pr` を使用してください。

> **⚠️ 注意:**
> エージェント環境（サンドボックス）では `git merge` 等の権限が制限されているため、**エージェント自身はマージを実行せず、ユーザーにコピー＆ペースト用のコマンドブロックを提示します。**

---

## 1. 現状分析
- **目的:** 現在のブランチ名と作業ツリーの状態を確認する。
- **アクション:**
  - `git status` で作業ツリーがクリーンであることを確認する（未コミットの変更がある場合は、まずコミットを促す）。
  - `git branch` で現在のブランチ名（マージ対象）を把握する。

## 2. マージコマンドの提示（ユーザー実行依頼）
- **目的:** ユーザーが自身のターミナルで安全にマージと掃除を実行できるようにする。
- **アクション:**
  - 現在のブランチ名をもとに、以下の処理を行う Bash 用のコマンドブロック（```bash）を出力する。
    1. `git checkout main`
    2. `git pull origin main`
    3. `git merge <対象ブランチ> --no-ff -m "Merge branch '<対象ブランチ>' into main"`
    4. `git push origin main`
    5. `git branch -d <対象ブランチ>`
    6. `git push origin --delete <対象ブランチ>`
    7. `git fetch --prune`
  - ユーザーに対し、上記コマンドをコピー＆ペーストして実行し、結果に問題がないか確認するよう依頼して終了する。
