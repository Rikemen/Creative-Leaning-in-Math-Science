# Pull Request Creation Planner (日本語)

**トリガー:** `/make-pr`

**説明:**
開発完了した機能ブランチをリモート（GitHub）へプッシュし、チーム開発の標準フローである**プルリクエスト（PR）を作成**するためのコマンドを立案・提示します。
コードレビューやCI（自動テスト等）による安全確認を行いたい場合に、`/merge` の代わりに使用します。

> **⚠️ 注意:**
> エージェント環境（サンドボックス）では `gh` コマンド等を使用したネットワーク通信や認証がブロックされる場合があるため、**エージェント自身はPR作成を実行せず、ユーザーにコピー＆ペースト用のコマンドブロックを提示します。**

---

## 1. 現状分析
- **目的:** 現在のブランチ名と作業ツリーの状態を確認する。
- **アクション:**
  - `git status` で作業ツリーがクリーンであることを確認する（未コミットの変更がある場合は、まずコミットを促す）。
  - `git branch` で現在のブランチ名（プッシュ対象）を把握する。

## 2. PR作成コマンドの提示（ユーザー実行依頼）
- **目的:** ユーザーが自身のターミナルで安全にプッシュとPR作成を実行できるようにする。
- **アクション:**
  - 現在のブランチ名をもとに、以下の処理を行う Bash 用のコマンドブロック（```bash）を出力する。
    1. `git push -u origin <対象ブランチ>`
    2. `gh pr create --web` または `gh pr create --fill` （※用途に応じて併記）
  - ユーザーに対し、上記コマンドをコピー＆ペーストして実行し、GitHub上でプルリクエストを作成するよう依頼して終了する。
