

# Sandbox Command Safety (サンドボックスコマンド安全規約)

**Activation:** This rule is **ALWAYS ON** for all terminal command operations.

> **Positioning:** `senior-engineer-conduct.md` の「Safety Over Obedience」原則を、
> サンドボックス環境での **コマンド実行制約** に具体化したルールです。

## 原則

サンドボックス環境には権限制約があり、一部のコマンドは実行できない。
実行不可能なコマンドを無理やり繰り返し試行するのは、時間の浪費であり、
ユーザーの信頼を損なう行為である。

## 行動手順

### 1. 実行前の判断

以下に該当するコマンドは、**実行を試みる前に**ユーザーへ確認する:

| カテゴリ | 具体例 |
|----------|--------|
| パッケージインストール | `npm install`, `pip install`, `brew install` 等 |
| グローバルツール実行 | `npx`, `firebase`, `gcloud` 等（ローカルの `./node_modules/.bin/` 経由は除く） |
| ネットワーク通信 | `curl`, `wget`, `ssh`, API呼び出し等 |
| システム設定変更 | `sudo`, `chmod`, `chown`, システムレベルの設定変更 |
| デプロイ・公開操作 | `firebase deploy`, `vercel`, `netlify deploy` 等 |

### 2. 実行失敗時の対応

コマンド実行が**権限エラーやサンドボックス制約で失敗**した場合:

1. **同じコマンドを再試行しない**（リトライは無意味）
2. ユーザーに以下を明確に伝える:
   - 🚫 **失敗したコマンド**と**エラー理由**
   - 💻 **ユーザーに手動で実行してほしいコマンド**（コピペ可能な形式で提示）
   - 📋 コマンドの**実行順序**がある場合はその順番
   - ✅ 実行後に**期待される結果**（何が起これば成功か）

### 3. 出力フォーマット

ユーザーへの依頼は以下の形式で行う:

```
⚠️ サンドボックス環境の制約により、以下のコマンドを実行できませんでした。
お手数ですが、ターミナルで以下を実行してください:

\`\`\`bash
# 1. [説明]
コマンド1

# 2. [説明]
コマンド2
\`\`\`

✅ 成功すると「[期待される出力]」が表示されます。
実行が完了したら教えてください。
```

### 4. 禁止事項

- ❌ 権限エラーが出たコマンドの再試行（`ask_permission` で権限を要求する場合を除く）
- ❌ `sudo` を付けての強制実行
- ❌ 失敗を黙殺して次の作業に進む
- ❌ 代替手段を試さずに諦める（ローカルパスでの実行など、サンドボックス内で可能な代替がある場合は試行する）
