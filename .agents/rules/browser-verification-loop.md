

# Browser Verification Loop Guard (ブラウザ検証ループ防止)

**Activation:** This rule is **ALWAYS ON** when using the `browser_subagent` tool.

## 原則

ブラウザサブエージェントによる検証は、スクロール操作やDOM操作が不安定になりやすく、
同じ検証を繰り返してユーザーの時間を浪費するリスクがある。
**同じ目的の検証が3回失敗・中断した場合、それ以上の自動検証は即座に中止する。**

## 行動手順

### 1. 検証カウントの管理

ブラウザサブエージェントで以下の**同一目的の操作**を行う際、失敗・中断・タイムアウトの回数を追跡する:

- 特定要素へのスクロール
- 特定ページへの遷移と表示確認
- DOM要素のクリックやインタラクション
- スクリーンショットの取得

### 2. 3回到達時の行動（厳守）

同一目的の操作が **3回** 失敗・中断した場合:

1. **即座にブラウザサブエージェントの使用を中止する**
2. **ユーザーに以下を報告する:**
   - 何を検証しようとしたか
   - どこで詰まったか（具体的なエラーや症状）
   - 取得済みのスクリーンショットや部分的な成果
   - ユーザー自身で確認すべきポイント（URLやUI操作手順）
3. **ユーザーに手動確認を依頼する**

### 3. 予防策

ブラウザサブエージェントを使用する際は、以下を心がける:

- **スクロールは小刻みに**: `Dy` の絶対値は 500 以下に抑える
- **1回のサブエージェントに詰め込みすぎない**: 確認項目を3つ以内に絞る
- **JavaScript実行（`javascript:` URL）は使わない**: サンドボックスでブロックされる
- **ページリロード後は待機**: `wait` で 2000ms 以上待ってからDOM取得する

### 4. 禁止事項

- ❌ 「次こそうまくいくかも」と4回目以降の同一検証を試みること
- ❌ 別のアプローチで同一目的を達成しようとリトライし続けること（3回の合計でカウント）
- ❌ ユーザーに報告せずにサイレントに検証を諦めること
