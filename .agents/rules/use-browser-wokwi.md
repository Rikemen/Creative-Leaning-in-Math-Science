# Use Browser Wokwi (シミュレーション環境の原則)

## 目的
ESP32やArduinoなどのマイコン開発におけるシミュレーションは、VSCode拡張機能ではなく、**ブラウザ版の Wokwi (https://wokwi.com)** を使用することを原則とします。

## 理由
VSCode拡張機能（Wokwi for VS Code）は、ローカル環境（Arduino CLIやPlatformIO等）でのコンパイル済みバイナリファイルを要求するケースがあり、環境構築の手間やパス設定のエラーリスクが高いです。
ブラウザ版Wokwiであれば、コードを入力するだけでクラウド上で即座にコンパイル・実行されるため、プロトタイピングのハードルを大幅に下げることができます。

## エージェント（AI）への行動ガイドライン
1. ESP32やArduinoのプロジェクトを立ち上げる際、Wokwi拡張機能専用の設定ファイル（`diagram.json` や `wokwi.toml`）は**作成しないでください**。
2. シミュレーションの実行をユーザーに案内する際は、以下のステップを提示してください。
   - ブラウザで Wokwi (https://wokwi.com) を開く。
   - `xxx.ino` のコードをコピー＆ペーストする。
   - 画面上で必要な部品（センサー、サーボなど）を追加し、配線する。
   - 実行ボタンを押してシミュレーションを行う。
