# Create Minutes (議事録生成)

**トリガー:** `/create-rop`

**説明:**
提供された打ち合わせの文字起こしデータ（テキスト）を元に、構造化された議事録を自動生成します。

---

## 1. 実行プロンプト・指示

- ユーザーから提供された指定されたテキストファイルを読み込みます。
- 文字起こしデータから文脈を読み取り、以下の「出力フォーマット」に従って議事録をマークダウン形式で生成してください。
- 議事録生成日時については、エージェントが持つシステム時刻（`knowledge-cutoff-awareness`スキル等）を利用して現在日時を記入してください。
- 情報が不足している項目（参加者の会社名、期日など）がある場合は、「[要確認]」または「不明」と記載し、最後の「ユーザーへの確認事項」で具体的に質問してください。

## 2. 出力フォーマット

以下のマークダウンテンプレートをそのまま使用して出力してください。

```markdown
# 議事録: [打ち合わせのタイトルを推測して簡潔に記載]

- **打ち合わせ日時**: [YYYY年MM月DD日 HH:MM - HH:MM]
- **議事録生成日時**: [YYYY年MM月DD日 HH:MM]
- **議事録作成者**: [作成者名 または Antigravity]
- **打ち合わせ参加者**:
  - [会社名]: [氏名]
  - [会社名]: [氏名]

## アジェンダ

- [アジェンダ項目1]
- [アジェンダ項目2]

## 決定事項

- [決定事項1]
- [決定事項2]

## ネクストアクション

| タスク名     | 担当者     | 期日         |
| :----------- | :--------- | :----------- |
| [タスク内容] | [担当者名] | [YYYY/MM/DD] |
| [タスク内容] | [担当者名] | [YYYY/MM/DD] |

## 保留事項

- [保留・継続検討となった事項があれば記載、なければ「なし」]

## 備考

- [その他、特記事項や重要な発言など]

---

## 署名欄

- **議事録送付日**: [YYYY/MM/DD または 追記をお願いします]
- **署名期日**: [YYYY/MM/DD または 追記をお願いします]

**[相手先会社名] ご担当者様 署名:**

---

---

## ユーザーへの確認事項

_AIアシスタントからのメッセージ:_
文字起こしデータから以下の情報が特定できませんでした。議事録の完成に向けてご確認をお願いいたします。

- [確認事項1（例：〇〇のタスクの期日が明言されていませんでした）]
- [確認事項2]
```
