## 2つの操作モード

開始画面で「カメラで遊ぶ」または「マウスで遊ぶ」を選ぶ。カメラは専用の設定画面で接続・中央登録・動く範囲の調整と練習を行い、「この設定でゲームへ」で本番へ進む。マウスと同じ背景・ヒーロー・ビーム・カード・音を使用する。ゲーム中は設定項目を表示せず、骨格映像も初期状態では非表示。「骨格を表示／骨格を隠す」で右側の映像を切り替えられる。隠しても身体操作は継続する。カメラの結果画面からの再挑戦はカメラ準備へ戻り、勝手にマウスへ切り替わらない。「あそびかたを選ぶ」で進行を止めてモードを変更できる。途中の問題・HP・得点は引き継ぐ。マウスにはタッチとキーボード操作も含む。

[2モードの検証記録](docs/input-modes-verification.md)。実人物のカメラ操作は未確認、未デプロイ。

カメラ版はテレビ・PC向けに16:9のゲーム領域を確保し、骨格モニターは必要なときだけ右側に表示。1280×720・1366×768・1920×1080で、中央登録からプレイまでページのスクロールなしで操作できることを確認した。発射は両手首の距離で判定し、近づけると発射、離すと停止する。狙いは体の左右移動で合わせる。[手首操作・16:9画面の検証記録](docs/wrist-input-tv-verification.md)。

## ローカル起動（前提ツール導入後）

このフォルダを作業ディレクトリにして実行する。Firebase CLIが必要。SDKやCLIの依存インストールはまだ行っていない。

```bash
npm run dev
```

Hosting EmulatorのURLは http://127.0.0.1:5100 。「はじめる」を押し、正解カードを約0.8秒押し続けると破壊して1点。次問では一度離してから再び押す。間違いはバリアで防がれ、減点なし。60秒で結果が表示され「もういちど」で再プレイできる。一時停止・タブ非表示では時計を止める。キーボードはTabでカードを選びSpace／Enterを保持して発射できる。

開始画面の「カメラで遊ぶ」で映像のみを取得し、ml5.js 1.3.0をオンデマンドで読み込み、MoveNet SINGLEPOSE_LIGHTNINGを起動する。準備中はゲームの時間を止める。30秒以内に準備できない場合や許可拒否・接続切れでは理由と再試行を表示。「マウス・タッチであそぶ」でカメラを停止し、進行中なら同じ問題・HP・得点から再開する。「カメラを止める」、タブ非表示、ページ離脱でもカメラを解放する。音声取得・録画・映像送信は実装していない。ライブラリとモデルの取得には外部通信が必要。プレビューには鏡写しの映像に合わせて肩・肘・手首の目印を表示する。低信頼度の関節は表示せず、推論開始から250ms以上古い結果も除外する。準備完了後の練習欄で「ここをまんなかにする」を押すと、身体の左右移動で4枚のカードに照準が移る。「動くはんい」で必要な動きの大きさを変更でき、変更後は中央を登録し直す。開始前の練習では時間と得点は変わらない。カメラで開始後は60秒のゲームへ進む。カメラ停止はゲームを一時停止し、タッチへ切り替えても問題・HP・得点を保持する。手首を認識できない間は発射を停止する。肩も認識できない状態が約1秒続くと時計を止め、肩の認識が3秒続くと同じ問題・HP・得点から再開する。認識待ちは問題の下に案内し、ゲーム全体を覆わない。途中で見失うとカウントダウンをやり直す。「Ⅱ（一時停止）」やタッチ切替で自動再開を取り消せる。手動停止後のカメラ再開も同じ準備とカウントダウンを通る。

停止は起動したターミナルでCtrl+C。ポート5100が使用中なら、既存サーバーを確認してから起動し直す。Auth／Firestoreも起動する場合は `npm run dev:firebase`。

`.firebaserc` の既定値はEmulator用の `demo-calc-and-shot-beam`。`production` は本番の `calc-and-shot-beam`。`firestore.rules` は構成準備用の全拒否で、実装時に所有者・公開データの権限を追加する。

## 初回のHosting公開

静的HTMLなのでビルドやFirebase Web SDKの登録は不要。プロジェクトを作成したGoogleアカウントでCLIにログインする。

```bash
cd /Users/rikemen/Documents/rikemen/Creative-Leaning-in-Math-Science/5_games/calc-and-shot-beam
firebase login:add
```

ブラウザでログイン後、`firebase login:list` で登録メールを確認し、`firebase login:use 作成したアカウントのメールアドレス` でこのフォルダのアカウントを選択する。その後に実行：

```bash
npm run deploy:hosting
```

Hostingだけを公開するため、Firestoreルールやデータは変更しない。成功時にCLIが表示するHosting URLを開く。既定サイトの場合は `https://calc-and-shot-beam.web.app/` で準備中ページ、`/asset-preview.html` で素材を確認できる。
