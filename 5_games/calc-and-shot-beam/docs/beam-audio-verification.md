# ビーム効果音の強化

2026-09-16。ローカル実装。未デプロイ。

## 変更

- 発射の瞬間に鳴る `beam-fire-v2.wav` と、保持中に繰り返す `beam-loop-v2.wav` を組み合わせる。短い衝撃・下降するレーザー音に、低音と電気的な倍音・脈動を重ねる。
- マウス・タッチ・カメラで同じ音を使用。発射音はビーム開始時に1回だけ鳴り、保持中のフレーム更新や照準移動では繰り返さない。
- 持続音の音量は0.24、発射音は0.32。持続音の立ち上がりと、両音の停止に32msのフェードを使用。消音・一時停止・タブ非表示は直ちに停止する。
- 素材プレビューのビームポーズも同じ2音を再生し、個別のプレーヤーから試聴できる。旧ビーム音は履歴として残し、他の効果音は維持する。
- 生成元は `assets-source/audio/generate_sfx.py`。外部作品の音源は使用しない。新しいWAV名と音声モジュールのURLでキャッシュを更新する。

## 確認

- `npm test`：91件成功。発射音の多重再生防止、停止フェード、素早い再発射、消音・一時停止、音源欠損時の継続を確認。
- [音源レポート](../assets-source/audio/sfx-report-v2.json)：44.1kHz・16bit・モノラル。発射音0.44秒・ピーク−6.38dBFS、持続音1.6秒・ピーク−7.13dBFS、クリップ0。ループの端の変化量は通常のサンプル間の最大変化量以下、先頭と末尾50msのRMS差は0.02dB。
- `node --test tests/e2e/beam-audio.test.cjs`：5件成功（Chrome headless、14.45秒）。2音源のブラウザデコード、マウスと模擬カメラでの実Audio再生、保持中の単発音の重複なし、離す・停止・消音、音源読み込み失敗時の得点、素材プレビューでの相互停止を確認。今回のブラウザ実行は音声関連の5件に限定。
- 生成を2回行い、8つのWAVと2つのQA JSONのSHA256が一致。旧6音源も変更前と一致。
- 実スピーカーでの聴感・端末別の音量は未確認。親子試遊はユーザー指示によりスキップ。

## 手元で試す

`http://127.0.0.1:5100/` を再読み込みし、「音あり」の状態でマウスまたはカメラでビームを出す。発射直後の衝撃音と、保持中の持続音を確認する。素材だけの試聴は `http://127.0.0.1:5100/asset-preview.html` の「ビーム発射」「ビーム持続」、または「ポーズ切替で音を鳴らす」を選んで「ビームポーズ」。

再生成：`python3 assets-source/audio/generate_sfx.py`。
