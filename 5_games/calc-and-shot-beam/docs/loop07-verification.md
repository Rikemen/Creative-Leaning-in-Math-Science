# Loop 03〜07 検証記録

2026-09-10。ローカルHosting Emulatorの `http://127.0.0.1:5100/` で確認。同日、ユーザー指示により本番Hostingへ公開。

## 本番公開確認

`npm test` の20テスト成功後、`npm run deploy:hosting` を実行。`calc-and-shot-beam` のHostingへ32ファイルを公開し、CLIのリリース成功を確認。

https://calc-and-shot-beam.web.app/ をChromeで開き、HTTP 200、p5キャンバス、4択、正解長押しで1点、一時停止を確認。ページ例外・HTTPエラーは0。60秒完走と再プレイは下記のローカル検証で確認済み。本番での実スマートフォン操作は未確認。Firestore・Auth・Functionsは今回の変更対象外。

## 実装

- `choices.js`：0〜18の中から近い誤答3枚＋正解1枚。正解位置はランダム。有限集合から抽出し、重複と無限再抽選を防止。
- `clock.js`：60秒の有効時間と中断時間の除外。
- `damage.js`：HP100、毎秒125ダメージ。正解だけ減少、誤答は不変。
- `session.js`：開始・出題・破壊・次問・結果、停止・再開、押しっぱなしの次問持越し防止。
- `input/pointer.js`：マウス・タッチ・キーボードを同じ入力へ変換。複数指の割込みとキャンセルを処理。
- `ui/game.js`・`styles/game.css`：仮カードの画面、残秒・得点・結果・再プレイ。
- `render/sketch.js`：p5.js 2.2.2で仮背景とビーム。画像素材・効果音・カメラは後続。

## 自動テスト

ゲームフォルダで `npm test`。20テスト成功。実装前は不足モジュールで失敗することも確認した。

- 問題の全100通りと初期10通り、無効設定。
- 全回答0〜18の4択、正解の4位置、重複なし。
- 59.999秒／60秒、重複停止・再開、FPS非依存のダメージ。
- 誤答、HP維持、二重加算防止、次問の再押下。
- 複数指・キャンセル、画面外への移動、古い時刻拒否。
- 60秒ちょうどの破壊は加点なし。フレーム処理が遅れても、それより前に成立した破壊は1回だけ加点。

## ブラウザ確認

Chrome headlessをPlaywrightで操作。テスト用の時間短縮機能はゲームへ追加せず、実時間で60秒経過させた。

1. p5のキャンバスが作成され、開始ボタンから4択を表示。
2. 誤答を900ms保持してバリア表示・得点0。
3. 正解保持で破壊・1点・次問へ。押しっぱなしのままでも加点が増えない。
4. 一時停止中に残秒が変わらず、再開可能。
5. 実時間60秒で結果に移行し、1枚と表示。再プレイで得点0に戻る。
6. 390×844で横はみ出しなし、各カードの操作領域44px以上。
7. Chromeのタッチイベントで長押しし、破壊・1点を確認。
8. 1280×720で4択が画面内に収まり、p5・ページ資源の読込を確認。ブラウザエラー・HTTPエラーともに0。[PC画面](loop07-pc.png)。

途中の検証スクリプトは既定の30秒待ちで終了確認がタイムアウトしたため、70秒に修正。ゲームの時間は変更していない。またブラウザアイコンの404を検出して同梱SVGへの参照を追加し、リソース確認を実施。

実物のスマートフォンでの指操作、カメラ、子供の試遊は未確認。自動ブラウザ検証を実機検証の代わりとは扱わない。p5とml5の互換確認はLoop 08以降。

## 手元で確認

`npm run dev` → http://127.0.0.1:5100/ → はじめる → 正解を長押し → 一度離す → 次問。60秒後に結果と再プレイを確認。終了時はターミナルでCtrl+C。今回の検証用エミュレーターは確認後に停止し、ポートを解放する。
