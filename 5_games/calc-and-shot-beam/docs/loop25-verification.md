# Loop 21〜25・体の重ね順

2026-09-14。ローカル実装。未デプロイ。

## 体を手前に表示

ユーザー指示により、`hero.js` の描画順を腕→体へ変更。`sketch.js` でもビームを人物より先に描き、体が腕・ビームより手前に見えるようにした。頭頂の補正値を730→690へ上げ、カードには重ならない範囲で上寄せ。仮図形も腕→体の順に統一。Loop 20時点の「腕を最前面」の仕様をこの指示で更新。

## 各Loopの実装

- **21**：`render/beam.js`。青い外光と白い芯、最大8個・周期400msの粒子。現フレームの発射点とカード下端を結び、停止時に即消える。動きを減らす設定では粒子なし。
- **22**：`render/feedback.js` とカードのCSS。正解カードはHP70未満で数字の左側にヒビ。誤答は曲面バリア。破壊時は6個・300msの破片で、同じ問題に再発生させない。停止・終了で消す。HPや得点の計算は変更しない。
- **23**：既存の合成WAV6種を採用。`assets-source/audio/generate_sfx.py` とseedによる再現可能な制作元を維持。新しい音源は生成していない。ブラウザデコードで長さ・ピーク・RMS・境界差を再計測。
- **24**：`audio/sound.js`。6つのAudio要素を再利用し、開始操作前は無音。開始・発射ループ・バリア・破壊・終了・練習ボタンを接続。ビームは音量0.18、それ以外0.35。通常の発射開始・停止に32msの音量フェード。消音・一時停止・非表示・ページ離脱では即停止。再生拒否・音源欠損をゲームへ伝播させない。
- **25**：`ui/screens.js` とゲーム画面。「れんしゅう」で1+1のカードを800ms保持して操作を試し、「ほんばんへ」へ進む。練習中の時間・得点は不変。開始／結果画面で加数1〜4・合計5以下、または加数0〜9・合計18以下を選択。結果から「もういちど」で得点と時間を初期化する。カメラの既存の照準練習・移動範囲設定も維持する。

- `npm test`：76件成功。ビームの粒子数・寿命・追従・停止、バリアと破壊の区別、破壊の重複抑止、無音開始・消音・音源再利用・再生拒否、練習と出題範囲・再挑戦を追加。
- `node tests/browser/loop25-check.cjs <Playwrightのモジュールパス>`：1280・844・390・320px幅で練習→本番、誤答、ヒビ、正解1点、音源再生、消音、停止を確認。844pxは高さ390pxで練習の本番ボタンまで見えることを目視確認。
