# Loop 16 背景の採用・検証

2026-09-14。背景素材の採用まで完了。本ゲームへの読込・合成はLoop 20、未デプロイ。

## 採用版

- 配信ファイル：[city.webp](../public/assets/images/city.webp)。1600×900、sRGBのCanvasから書き出したWebP、34,020 bytes、全画素不透過。
- 既存の内蔵image_gen生成背景を目視で確認し採用。文字・人物・腕・光線・カードなし。広い空と下部の控えめな街並みで、中心切り抜きにも対応する。今回は新規生成していない。
- 元画像：[original.png](../assets-source/images/city/v2/original.png)。1672×941、966,789 bytes。初版はそのまま保存し、v2の制作元にも未加工コピーを保存。
- 等倍比を維持するため元画像の上下を各0.25px相当切り抜き、1672×940.5から1600×900へ縮小。Chrome Canvas、高品質補間、WebP quality=0.9。容量は約96.5%削減。
- [実際の生成プロンプト・書き出し履歴](../assets-source/prompts/city-v2.json)に、初版の生成日と今回の書き出し日を分けて記録。

## 検証

`node tests/browser/background-check.cjs <Playwrightのモジュールパス>` を実行。スクリプトは一時HTTPサーバーを起動し、終了時に閉じる。採用版を書き出し直し、WebPのブラウザデコード、1600×900、全画素alpha=255をassertで確認。[結果JSON](loop16-background-results.json)。

現行ゲームのDOMへ検証用CSSだけを一時注入して合成。背景はcenter/cover、式・HUDは濃色の不透過面で保護。背景単体の検品のため仮の主人公とビームのCanvasは非表示。これは完成画面ではなく、Loop 20の合成時に守る可読性の確認。注入CSSはゲームの配信コードへ保存していない。
