# カメラ設定画面の分離

確認日：2026-09-14。ローカル実装。未デプロイ。

## 画面の流れ

1. タイトルの「カメラで遊ぶ」で専用の設定画面を開き、カメラを接続する。
2. 大きな映像で肩と両手首が映るようにカメラ位置を合わせる。
3. 「ここをまんなかにする」で中央を登録し、「動くはんい」を調整する。左右移動の照準と、手首を近づけたときの発射を練習カードで確かめる。
4. 「この設定でゲームへ」を押す。中央登録済みなら、マウス操作で一時的に手首や肩が映らなくなっても画面を進められる。カードとキャラを表示したまま、肩の認識が3秒続くと開始する。待機中は時間・HP・得点は変わらない。手首の認識は開始条件にしない。
5. ゲーム中は設定項目を表示しない。骨格映像も初期状態では隠し、必要なときだけ「骨格を表示」で右側に表示する。

「カメラ設定」で設定画面に戻ると、ゲームを停止して問題・HP・得点・残り時間を保持する。接続中のカメラと登録済みの中央位置・動く範囲を引き継ぐ。「この設定でゲームへ」で戻り、肩が映る位置で3秒待つと再開する。ビームは手首を離してから近づけて発射する。

動く範囲を変更すると中央位置の再登録が必要。中央未登録・カメラ停止・接続切れではゲームへ進めない。一時的な姿勢の認識欠損は画面遷移を妨げず、ゲーム画面で認識を待つ。「あそびかたを選びなおす」はカメラを停止してタイトルへ戻る。マウスへの切り替え時も進行中の問題・HP・得点を保持する。

## 実装

- `public/index.html`：設定画面とプレイ領域を別セクションに分離。調整・練習を設定画面へ移動。
- `public/js/ui/game.js`：設定への遷移、明示開始、停止・再開、骨格モニターの初期非表示と切り替え。
- `public/js/ui/camera-panel.js`：再設定時は接続済みのカメラを再起動せず、そのまま使用。
- `public/js/ui/aim-practice.js`：設定中の照準・発射プレビューと、カメラ接続・中央登録を条件に有効になる開始ボタン。現在の手首の見え方では無効化しない。
- `public/styles/camera-setup.css` / `game.css`：設定画面の2列配置、16:9のゲーム領域、必要なときだけ表示するモニター。

映像と骨格のDOMを設定画面とモニターの間で移動し、同じ動画・カメラ接続・姿勢認識を使用する。ゲーム中に設定欄が重なったり、非表示の設定操作がキーボードで選ばれたりしないよう、設定画面全体を非表示にする。

## 開始ボタンが押せない問題の修正

実際のローカル画面で、中央登録と照準は有効なのに、手首の認識が欠けて開始ボタンが無効になっている状態を確認した。旧条件は「中央登録済み」に加え、「その瞬間の肩・両手首と、手首を離した姿勢」まで必要としていた。そのため、マウスへ手を伸ばす操作で開始できなくなる。

ボタンとクリック処理の条件を「カメラ接続済み・中央登録済み」に統一。手首や肩の一時的な認識欠損はゲーム画面への遷移を妨げない。初回も再開時と同じ認識待ち・3秒のカウントダウンを使用し、その間は残り60秒・HP・得点を保持する。中央未登録、範囲変更後の再登録前、カメラ停止時は引き続き開始できない。

回帰テストでは、手首や全身の認識が欠けてもマウスで画面を進められることを確認する。開始待ちの条件は、下記の修正で肩の認識へ変更した。配信入口とUIモジュールのバージョンも更新し、再読み込み時に修正前の開始条件が残らないようにした。

## 全画面の認識待ちで止まる問題の修正

上記の最初の修正では、画面遷移後も両手首の認識を開始条件にしていたため、手首の認識が途切れると全画面の待機表示に留まっていた。現在は時計の開始・停止を肩と照準の認識で判断し、手首の認識はビームの発射だけに使用する。

認識待ちとカウントダウンは問題の下の短い案内へ変更し、暗転・ぼかし・全面ダイアログを表示しない。手動の一時停止、結果、タイトルは従来のダイアログを使用する。待機中の「Ⅱ」は自動再開を取り消して休む操作になる。

肩が見えていれば手首が不明・近い状態でも3秒後に時計が進む。手首不明ではビームだけを止める。同じ問題で一度発射準備済みなら500ms以内の手首欠損から再度保持して復帰できる。開始・次問・長い欠損後は手首を離して再準備するまで発射しない。肩が見えない状態が1秒続いた場合は時間を停止し、ゲーム表示を保ったまま肩の認識を待つ。[手首判定の安定化](gesture-stability-verification.md)を参照。

- [肩の認識待ちの画面](camera-ready-waiting.png)：ゲームを覆わず、残り60秒・4カード・ヒーローを表示。
- [手首を認識せず肩だけで開始した画面](camera-ready-playing.png)：残り59秒に進み、手首の案内を表示。カードのHP・得点は変化しない。
