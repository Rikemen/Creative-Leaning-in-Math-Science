# Loop 09 姿勢の整形

2026-09-11。ローカル `http://127.0.0.1:5100/` で確認。未デプロイ。

## 実装と座標の契約

- `public/js/input/camera.js`：推論開始時の単調増加時刻 `capturedAt` と `video.width/height` を、姿勢配列と一緒に通知する。時刻は推論完了時刻に置き換えない。厳密な撮影時刻ではなく、推論開始時刻である。
- `public/js/input/pose-normalizer.js`：ml5の未反転座標を、鏡写しの画像座標（左上原点、右方向x／下方向y、0〜1）へ変換。`left_shoulder` などの解剖学的な左右名は入れ替えない。`body-pose.js` の `flipped: false` を維持し、座標反転はこのモジュールで一度だけ行う。
- `shoulderCenter` は鏡写し画像上の肩の中点。`shoulderWidth` は元画像の横幅に対する肩間距離。`body` の各関節は肩の中点を原点、肩間のユークリッド距離を1単位とする。距離は元画像のピクセルで計算し、縦横比によるゆがみを防ぐ。
- 信頼度0.3未満、非有限・範囲外座標の関節を除く。両肩が有効でない／肩幅が画像幅の2%未満／複数人／関節名重複の場合は姿勢全体を無効にする。値は `POSE_SETTINGS` に集約し、実機調整は後続Loopで行う。
- `PoseNormalizer` は250ms以上古い結果を無効化。逆順・重複・未来・不正時刻で現在の結果を上書きしない。新しい未検出結果では以前の姿勢を消す。`get(now)` も鮮度を確認するため、次の推論が届かなくても古い姿勢を返さない。
- `projectPoint` は中央寄せ `object-fit: contain` と同じ倍率・縦横の余白を計算する。表示先は4:3のプレビュー内のSVG。映像だけをCSSで鏡写しにし、整形済みの目印は再反転しない。
- `public/js/ui/pose-preview.js` は肩・肘・手首だけを描画。無効な関節には線をつながず、鮮度切れで目印を消す。停止・タッチ切替・再試行でも以前の表示を破棄する。

照準、ポーズによる発射、認識喪失からのゲーム復帰はLoop 10以降。今回の変更で身体入力から得点は発生しない。

## 確認結果

`tests/unit/pose.test.js` を先に追加し、未実装による失敗を確認後に実装。`npm test` は **39件成功**（従来30件＋姿勢8件＋推論開始時刻の検証1件）。

左右反転・入力不変、横長／縦長映像の余白、解像度・移動・身体サイズに対する身体座標の不変性、低信頼度、欠落、不正座標、時刻の250ms境界、逆順・重複・未来の結果、未検出と再初期化を確認した。

Chrome headless＋Playwrightで、1280×720の合成映像と模擬姿勢を実際のUIへ入力。ml5の取得URLだけを検証用コードへ差し替え、本番コードには検証用の入力切替を追加していない。

1. 映像は鏡写し。4:3表示内の16:9映像に上下の余白が入り、肩の目印の計算位置とDOM描画位置の差はx・yとも0px。
2. 関節を水平方向に動かすと、映像と同じ鏡写し方向へ目印も移動する。
3. 片手首だけ低信頼度にするとその目印と接続線が消え、残り5関節を維持。
4. 未検出で全目印消去、新しい有効姿勢で再表示。推論を600ms遅延させると古い目印が消える。
5. タッチ切替で全映像トラックが `ended`、4択表示。停止後に遅い推論が完了しても目印が復活しない。
6. 1280×900と390×844の画面を目視。横はみ出しなし。ページ例外0件。

成果物：[ブラウザ結果](loop09-browser-results.json)、[PC](loop09-pose-pc.png)、[モバイル幅](loop09-pose-mobile.png)。画像は合成した線と点のみで、人物映像を含まない。

**未確認**：物理カメラでの肩・腕への重なり、実人物の認識精度、実スマートフォン／iPad、公開環境。Loop 08の実モデル読み込み確認と、今回の合成映像による位置検証を区別する。

## 手元で確認

`npm run dev` → `http://127.0.0.1:5100/` →「カメラをためす」→ 許可。肩と腕を映し、左右に動いて目印が映像に重なること、画面から離れると目印が消えることを確認する。「タッチであそぶ」で通常ゲームに戻れる。

単体テストは `npm test`。ブラウザ検証はChromeとPlaywrightが使える環境で `node tests/browser/pose-preview.cjs`。Playwrightがプロジェクト外にある場合は第1引数にそのモジュールの絶対パスを渡す。今回の実行では既存の同梱ランタイムを使用し、依存インストールや既存サーバーの停止は行っていない。
