## Loop 15時点の制作目標（採用座標は版2節を参照）

原点は左上、右が+x、下が+y、単位はpx。全画像1024×1024。画面の左右で記述し、解剖学的な左右やカメラの鏡写しと混同しない。

| 名前 | 共通画像上の座標・範囲 | 制作・検品ルール |
| --- | --- | --- |
| canvasOrigin | (0,0) | 3枚を同じ原点・同じ倍率で重ねる |
| shoulderLeft | (230,930) | 後頭部画像と両腕画像で一致。中心誤差±4px以内 |
| shoulderRight | (794,930) | 同上。各接合部は半径24px以上重ね、隙間を作らない |
| beamOrigin | (512,768) | 発射腕の手首の交点。可視の発射位置の中心誤差±4px以内 |
| heroBounds | x=222〜802、y=802〜1024 | 頭の上端はy=802以降。肩の接合点を含み、腕を描かない |
| armsBounds | x=52〜972、y=734〜1024 | 待機／発射どちらも範囲内。上端より上は透明 |
| idleHands | 左(350,790)、右(674,790) | 手の中心の目安±16px。肩の基準点は動かさない |

頭は発射点より下に置き、手・交点は腕レイヤーで頭より手前に描く。胴体の下端はキャンバス端で切れてよい。それ以外の輪郭は指定範囲内へ収める。画像の大半が透明になるのは、少ない素材で共通原点と等倍合成を維持するための意図した仕様。

## Loop 14の画面座標との対応

画像座標を(u,v)、合成枠の左上を(x0,y0)、一辺を600とすると、画面論理座標は `x=x0+u*600/1024`、`y=y0+v*600/1024`。その後 `layout.scale` を掛けて実画素へ変換する。縦横比は変えない。

| レイアウト | 合成枠（左上・一辺） | 画像の発射点を変換した値 | 人物の可視領域 |
| --- | --- | --- | --- |
| 横1600×900 | (500,300)、600 | (800,750) | x約530〜1070、y約730〜900 |
| 縦900×1600 | (150,870)、600 | (450,1320) | x約180〜720、y約1300〜1470 |

発射点は現在の [layout.js](../public/js/render/layout.js) の `emitter` と一致する。表の可視領域は当初の目標で、採用版の実測領域は版2節を参照。Loop 20で共通合成枠 `avatar` をlayoutへ追加済み。カード位置と発射点を保持する。

描画順は背景 → 後頭部・肩 → 待機または発射の腕 → ビーム → カード・数字・HUD → 停止等のオーバーレイ。ビーム経路は既存の `beamPath()` を使い、特に縦画面で下段カードの数字を横切らない。腕切替で画像原点・倍率・肩位置を動かさない。レイアウト変更時は画像を個別に動かすのではなく共通の合成枠を変更する。

背景は横画面で全体を表示、縦画面では縦横比を保つcover・中央揃えで切り抜く。端の建物が切れても意味が失われない構図にする。背景自体の文字・数字・重要な被写体は不可。式とHUDの背景には別途可読性を保つ面をコードで描き、白いカードを最も目立たせる。

## 出典管理と採用レビュー

制作元は `assets-source/images/<id>/<revision>/`、予定指示の実行後の記録は `assets-source/prompts/<id>-<revision>.json` に保存する。revisionはv2以降の未使用名。実際のプロンプト、生成日時・使用ツール、参照画像のパス、未加工画像、書き出し・配置調整内容、採否と理由を記録する。元画像と不採用案を削除せず、採用ファイルだけ上表の配信パスへコピーする。

出典は既存の内蔵image_gen生成物または同ツールによる新規・参照編集を予定する。外部素材を追加するときは入手URL・作者・利用条件を台帳に追記。予定プロンプトを実際に実行したと記録しない。

Loop 16〜19では各画像について以下を確認し、結果と画像を台帳へ記録する。

- ファイルの実寸・形式・透過をデコードで確認。人物のalpha外接範囲と各アンカーを実測する。
- 白・黒・採用背景の上で合成し、白縁、市松模様、半透明の汚れ、肩の隙間がないことを確認。
- 同じ原点・倍率で後頭部＋待機腕、後頭部＋発射腕を切り替え、肩の位置が±4px以内で一致することを確認。

- 横1600×900と縦900×1600、および実画面幅320・390・844・1280pxで、式・数字・HPが読めることを確認。背景の中央切り抜きも確認。
