## 目的と合格目安

計算力ではなく、指定したカードを身体で狙って発射できるかを調べる。親10回→子供10回の順で実施する。

- 子供が10回中8回以上、大人の操作代行なしで指定カードへ発射できる。
- 子供の10回の試遊中、通常姿勢での意図しない発射が1回以下。
- 左端・右端を含め4枚を試す。認識喪失から同じ問題・HP・得点で復帰できるかも別途確認する。

以下は試遊を実施する場合の判定基準。今回はスキップするため、Loop 14へ進む前提条件にはしない。親の結果は比較用で、子供の結果を代用しない。

## 実施手順

1. ゲームフォルダで `npm run dev`。既に起動済みならそのまま [ローカル画面](http://127.0.0.1:5100/) を開く。公開サイトはLoop 12までの今回の変更をまだ配信していないため使わない。
2. 「カメラをためす」で許可し、親が肩・肘・手首を映す。「ここをまんなかにする」で校正する。最初の「動くはんい」は「ふつう」。
3. 練習カードで左右へ移動し、目印が肩・腕に重なるか確認する。腕を組んで「ビームのポーズ！」になり、ほどくと発射姿勢の表示が消えるか試す。ここは採点前の練習。
4. 「カメラで はじめる・つづける」で本番へ。一度腕をほどく。カードを**左から1・2・3・4番目**として、下表の順に狙う位置を指定する。画面に書かれた数字を問題の答えとして解かせる必要はない。
5. 各回、最初に腕をほどいて約2秒待ち、意図しないビームが出ないか観察。その後、指定位置へ動き、腕を組んで発射する。指示は声かけにとどめ、大人が身体や画面を操作した場合は「補助あり」として成功数に含めない。
6. **指定カードにビームが届けば成功**。不正解カードのバリアも、操作としては成功。ゲームの得点は成功回数の代わりにしない。狙い違い、撃てない、補助が必要、中止は失敗として理由を分ける。疲れたら休み、未実施の回は失敗数に入れず残す。
7. 60秒で結果画面になったら再開して残りを試す。再開時のカメラ準備・中央校正をやり直し、再開回をメモする。時間切れで試せなかった回を操作失敗と混同しない。
8. 親10回が終わったら休憩し、子供に交代。**子供の肩幅と中央位置で校正し直す**。同じ手順で10回記録する。
9. 下の復帰確認と感想を記録する。調整するなら、まず距離・照明・画面内の腕を確認し、その後1項目だけ変更して再試遊する。

横一列のPC／横向きタブレットを優先する。狭幅でカードが2段になる場合は「左上1・右上2・左下3・右下4」で記録し、横一列の結果と混ぜない。
