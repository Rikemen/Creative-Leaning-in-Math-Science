# 手首操作と16:9カメラ画面の検証

確認日：2026-09-14。ローカル実装・自動テストの結果。未デプロイ。

この記録は設定画面を分離する前の実装を対象とする。手首の距離による発射判定は維持し、現在の画面遷移は[カメラ設定画面の検証記録](camera-settings-verification.md)を参照。TVの画面画像は現行テスト実行時に更新される。

## 操作の変更

- 体の左右移動でカードを狙い、両手首を近づけて250ms保持するとビームを発射する。離すと停止する。
- 発射条件から腕の交差と肘の認識を除外。肩と両手首は引き続き必要。
- 手首間の直線距離を肩幅で正規化する。肩幅の0.45倍以下で発射準備、0.65倍以上で停止。その間では直前の状態を保ち、境目の揺れによる点滅を抑える。
- 開始・次問・認識喪失後は一度手首を離す。古い姿勢の除外、認識喪失後の停止、手首を離した状態での3秒の復帰待機は維持する。
- 骨格モニターに両手首を結ぶ破線と中点を表示。近いと線が黄色になる。モニターを隠しても認識とゲーム操作は継続する。

判定は `public/js/input/gesture.js`、描画は `public/js/ui/pose-preview.js`。手首の中点による照準移動は行わず、従来の体の左右移動を使用する。

## テレビ・PC画面

マウス版と共通のアリーナを使用し、カードは上側、ヒーローは下側に表示。ゲーム領域を16:9に保ち、右側の骨格モニターと中央登録などの準備操作を画面内に収める。画面幅1000px以上・アスペクト比4:3以上にこの配置を適用し、狭い画面では既存の配置を使用する。

## 実行結果

- `npm test`：81件成功。手首の左右順・高さの違い、肘なし、距離の境界、判定の揺れ、欠損・古い姿勢・再認識を含む。
- `node --test tests/e2e/game.test.cjs`：7件成功。模擬姿勢による発射・停止・加点、実時間60秒のカメラゲームと再挑戦を含む。
- `node --test tests/e2e/camera-monitor.test.cjs tests/e2e/startup.test.cjs tests/e2e/tv-layout.test.cjs`：5件成功。肘なし・骨格非表示中の加点、起動キャッシュ、3解像度の表示を含む。
- Chrome headlessの画面を保存し、1280×720と1920×1080の配置を目視確認。

カメラ映像・姿勢はテスト内の合成データ。実人物の手首認識精度、カメラからの距離や照明の違い、実際のテレビから離れた位置での読みやすさは未確認。親子試遊はユーザー指示によりスキップ。

## ローカルでの確認方法

`http://127.0.0.1:5100/` を再読み込みし、「カメラで遊ぶ」からカメラを接続。「ここをまんなかにする」を押し、両手首を離すと開始する。体を左右に動かしてカードを選び、両手首を近づけて保持するとビームが出る。「骨格を隠す／骨格を表示」でモニターを切り替えられる。
