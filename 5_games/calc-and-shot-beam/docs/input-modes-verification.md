# カメラ・マウスの2モード

2026-09-14。未デプロイ。

## 調査と変更

従来も `ui/game.js` のGameSessionを身体入力とポインター入力で共有し、`render/sketch.js` の背景・人物・ビーム描画を使用していた。一方、接続確認・仮の練習カードが常設され、本番との区切りが曖昧だった。

開始ダイアログに「カメラで遊ぶ」「マウスで遊ぶ」を追加。カメラ選択後は接続と中央登録の準備画面、本番開始後は素材を適用した共通ゲーム画面へ切り替える。音・HP・得点・60秒のルールも共通。ゲーム中は準備用の仮カードを表示しない。

カメラでの停止・結果からの再開もカメラ準備へ戻る。「あそびかたを選ぶ」はゲームを停止しカメラを解放する。途中で別モードを選んでも問題・HP・得点を保持する。拒否時は準備画面からマウス・タッチへ進める。

## 起動不良の修正とヒーロー風トップ（2026-09-14）

既存のアプリ内ブラウザで、カメラ入口を押しても変化しない状態を再現。素材はreadyだが、現在のgame.jsが設定するdata-modeが存在せず、初期HTMLの文言が残っていた。版付き起動エントリーへの変更後に同じタブでモードが初期化され、カメラ要求・準備完了・身体検出まで確認できた。古いJavaScriptと新しいHTMLの不一致が原因と判断した。物理カメラでの全身操作・60秒完走は確認していない。

boot.jsで版付きgame.jsを読み込み、失敗時はページ上にエラーを表示。変更したcamera-panelも版付きURLで読む。非同期起動がwindow.load後になっても描画を開始する。FirebaseのJSにno-cacheを追加した（未デプロイ、既存ローカルサーバー再起動はしていない）。今後、HTMLと起動処理を同時変更する際は版を更新する。

トップ画面を銀色パネル・赤青ボタン・ヒーロー・光線で構成し、専用title.cssへ分離。既存画像を再利用し、新規画像生成はしていない。カメラ準備は許可→中央登録→開始の3段階を表示する。

単体80件成功。追加のstartup.test.cjsは旧エントリー回避と読み込み失敗表示に成功。従来7件のE2Eも再実行。既存のアプリ内タブと390pxのスクリーンショットで新トップを目視確認。

## ゲーム中の骨格モニター（2026-09-14）

カメラ映像と肩・肘・手首の骨格線を右上に常設。ゲーム本体は街・ヒーロー・ビームの共通描画を維持する。「骨格を隠す／骨格を表示」はモニターの表示だけを変更し、カメラ停止・入力解除・時計の停止を行わない。準備中と本番で同じvideoとSVGを共有し、映像の再接続や二重取得は行わない。別モードへ戻ったときはモニターを隠し、従来どおりカメラを解放する。

PCではゲームの右隣、900px以下はゲームの上側右端へ配置し、問題・HUD・カードに重ならない。1280×900、844×390、390×844で検証。camera-monitor.test.cjsで、骨格線表示→非表示→トラック継続→身体入力で加点→再表示→モード退出時解放に成功。合成映像・模擬姿勢による確認であり、実人物の操作精度の検証ではない。

画面：[PC](camera-monitor-1280.png)、[390px](camera-monitor-390.png)。未デプロイ。

## カメラ準備画面の素材統一（2026-09-14）

準備画面にも街背景、光線、ゲームと同じhero-back・arms-idle・arms-fireを使用。setup-hero.jsは共通のloadAssets・drawHeroを使い、中央登録前からヒーローを表示し、腕組みで発射姿勢へ切り替える。時計と得点は準備中に進めない。接続状態と中央登録・開始操作は銀色パネルにまとめ、右上の骨格モニターを維持する。専用camera-setup.cssにスタイルを分離。

1280×900・844×390・390×844で準備画面を保存・目視確認。模擬姿勢による準備中の発射姿勢切替、時間60・得点0維持、本番開始後の加点、骨格表示切替とカメラ解放、起動エラー表示の2テストに成功。実人物の操作精度は未確認。

[準備画面PC](camera-setup-1280.png)・[準備画面390px](camera-setup-390.png)。未デプロイ。

## カメラの別画面を廃止（2026-09-14）

従来の準備専用イラスト画面とsetup-hero.jsを廃止。カメラ選択直後からGameSessionの問題・4択と共通アリーナを表示し、準備中は時計を停止する。中央登録・認識状態・接続操作は右側の骨格モニター内へ移動。中央登録後にopen姿勢を検出すると自動でゲーム開始し、firing姿勢からBodyInputを通じて同じカードへビームとダメージを適用する。本番では準備コントロールを隠し、骨格モニターの表示切替だけを残す。

カメラ選択直後のアリーナ表示、中央登録からの自動開始、骨格非表示中のクロス発射と得点を模擬姿勢で確認。[準備状態](camera-unified-ready.png)・[クロス発射](camera-unified-fire.png)。実人物での認識精度は未確認。未デプロイ。
