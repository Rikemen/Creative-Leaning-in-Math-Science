# Loop 14 UIレイアウト検証

実施日：2026-09-11。対象：ローカル http://127.0.0.1:5100/ 。未デプロイ。

## 実装

- `public/js/render/layout.js` に式、ヒント、HUD、4カード、数字の安全領域、仮の主人公・腕・発射点を集約。HTMLとp5が同じ座標と倍率を使う。
- アリーナ幅700px以上は1600×900の4列、700px未満は900×1600の2段配置。ResizeObserverで切り替え、ゲームの進行状態は保持する。
- ビームの標的をカード下端に置き、縦画面では中央のカード間を通る経路にする。数字の安全領域とビームを分離した。
- 主人公・腕はコードによる仮図形。正式画像・音・後続Loopの演出は今回の対象外。

## 確認結果

`npm test`：66件成功（新規レイアウト4件を含む）。カード相互、式、HUD、ヒント、フィードバックの重なり、腕・主人公と数字の安全領域、ビームの太さを含めた安全領域を検証。

`node tests/browser/layout-check.cjs <Playwrightのモジュールパス>`：Chromeで以下の6サイズを検証。全サイズで論理座標とDOMの位置・寸法が1px未満の誤差で一致。数字が安全領域内に収まり、カードは44px以上、ページの横はみ出しなし。誤答バリア、正解1点、一時停止ダイアログのアリーナ内表示に成功。JavaScript例外なし。

## 手元での確認

ローカル画面で「はじめる」を押し、誤答カードを長押しする。数字の下にビームが届くことを確認。画面幅を狭めると4カードが2段に変わる。正解カードを約0.8秒押し続けると1点。

親子試遊はユーザー指示によりスキップ。今回のブラウザ検証はデスクトップChromeの画面サイズ変更であり、スマートフォン実機のタッチ操作や実人物のカメラ認識を検証したものではない。
