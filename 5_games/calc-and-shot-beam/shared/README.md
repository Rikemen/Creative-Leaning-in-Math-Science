# クライアント・サーバー共通のルール

- `game/`：問題生成、ダメージ計算、時間境界など、表示・SDK・通信に依存しないロジック。
- `contracts/`：結果・イベント・API入出力の定義、共有できる検証仕様。

ここに置くものは公開してよいコードだけ。秘密情報とサーバーの所有者認可はFunctions側へ置く。

共用が必要になるまでは空の配置先とする。ブラウザの `public/js/game/` は画面進行を担当し、共通ルールを二重実装しない。共用を実装する際はビルドで `public/js/generated/` とFunctionsの配信成果物に取り込む。現時点ではビルド・生成物は存在しない。
