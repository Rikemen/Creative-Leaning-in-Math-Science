# 01 こちらを見る動物

カメラで来場者の位置を認識し、その方向へ首を向ける作品。
「人工生物」シリーズの最初の1体であり、以降の作品が土台にする **見る → 向く** の基本機能を作る。

## コンセプト

動物が人に気づいて振り向いた瞬間に、「何かが生きている」と感じさせる。
正確に追従することよりも、**気づいて、少し遅れて、振り向く** という生き物らしい動きを優先する。

## 完成イメージ

- 来場者がカメラの前に立つと、動物の首がその方向へ向く
- 人が左右に動くと、首が滑らかに追いかける
- 人がいなくなると、正面（初期位置）にゆっくり戻る

## システム構成

```text
Camera
↓
p5.js + MediaPipe（ブラウザ）  ← pc/
↓
人の位置を取得（画面上のX座標）
↓
角度に変換・動きの味付け（平滑化・遅れ・見失い）
↓
WebSocket（Wi-Fi）
↓
ESP32                          ← esp32/
↓
Servo
↓
首を動かす
```

| 層 | 役割 | 置き場所 |
|---|---|---|
| 認識 | カメラ映像から人の位置を取得する | [pc/](./pc/) |
| 行動 | 位置を角度に変換し、生き物らしい動きに整える | [pc/](./pc/) |
| 通信 | 角度を WebSocket で ESP32 へ送る | [pc/](./pc/) |
| 制御 | 受け取った角度でサーボを動かす | [esp32/](./esp32/) |
| 機構 | 首を動かす台座・パーツ | [cad/](./cad/) |

### 役割分担の方針

- **考えるのは PC、動かすのは ESP32。** 動きの味付けは試行錯誤が多いため、書き換えてすぐ確かめられるブラウザ側に置く。ESP32 は「受け取った角度にサーボを合わせる」だけにして、書き込み回数を減らす。
- **ESP32 が WebSocket サーバーになる。** ブラウザは WebSocket サーバーになれないため、ESP32 側で待ち受け、ブラウザから接続する。中継サーバーが不要になる。
- **PC 側は p5.js を使う。** 既存の p5.js スキルを活かし、カメラ映像と「仮想の首」を同じ画面で確認しながら作れる。

### 通信の形式

角度を整数のテキストで送る（例: `90`）。
目で読めるため、デバッグしやすいことを優先する。

## 必要なもの

| 種類 | 部品 | 備考 |
|---|---|---|
| マイコン | Freenove ESP32（ESP32-WROOM-32E） | Wi-Fi で WebSocket 通信する |
| ケーブル | USB-C ケーブル（データ通信対応） | 充電専用ケーブルでは書き込めない |
| アクチュエータ | サーボモーター（SG90 など） | 首の左右回転用。信号線は GPIO 13 など出力可能なピンへ（GPIO 34〜39 は入力専用で使えない） |
| 入力 | Webカメラ | PC に接続（ノートPC内蔵カメラでも可） |
| 電源 | サーボ用の外部5V電源 | サーボの電流で ESP32 がリセットされるのを防ぐ。**GND を ESP32 と共通にする** |
| 配線 | ブレッドボード ×2、ジャンパーワイヤー | ボード幅が広いため2枚並べると両側のピンが使える |
| 処理 | PC（Chrome 推奨） | p5.js と MediaPipe を動かす |

## 設計メモ

### 位置から角度への変換

カメラ画面上の人のX座標（0〜1）を、サーボ角度（例: 30°〜150°）に線形変換する。
サーボの可動限界（0°・180°）付近は負荷がかかるため、余裕を持たせた範囲にする。

### 動きの味付け（生き物らしさ）

- **平滑化:** 目標角度へ一気に飛ばず、少しずつ近づける（ローパスフィルタ）
- **反応の遅れ:** 人を検出してから動き出すまでに短い間を置く
- **見失い時の挙動:** 検出が途切れても即座に戻らず、一定時間待ってから正面へ戻る

### 送信頻度

カメラのフレームごと（約30回/秒）に送ると、ESP32 側の処理が追いつかず動きが遅れることがある。
角度が変化したときだけ送り、さらに送信間隔を間引く。

### Wi-Fi の接続情報

SSID とパスワードはソースコードに直接書かず、`secrets.h` に分けて `.gitignore` で除外する。
Git には見本の `secrets.sample.h` だけを入れる。

**セットアップ手順**

1. `esp32/looking_animal/secrets.sample.h` を、同じフォルダに `secrets.h` という名前でコピーする
   ```bash
   cp esp32/looking_animal/secrets.sample.h esp32/looking_animal/secrets.h
   ```
2. `secrets.h` の `WIFI_SSID` と `WIFI_PASSWORD` を自分の環境の値に書き換える（2.4GHz の SSID を使う）
3. `looking_animal.ino` から `#include "secrets.h"` で読み込む

> Arduino IDE はスケッチフォルダ内のファイルしかビルドに含めないため、`secrets.h` は `.ino` と同じフォルダに置く。
