Phase 4 — ESP32とサーボのシミュレーション

PC側は角度を「考える」担当、ESP32は受け取った角度へ「動かす」担当です。ESP32側を単純にすると、作品の動きを調整するたびにマイコンへ書き込まずに済みます。

WokwiC++ / ArduinoDEVLOG 完了

サーボの3本の線

信号線 → GPIO 13

ESP32が50Hzのパルス信号を出し、サーボへ目標角度を伝えます。

電源線 → 5V

モーターを回す電力です。シミュレータではESP32の5Vへ接続します。

GND → GND

電圧の基準をそろえます。信号を正しく読むために必要です。

実機では外部電源

サーボの大きな電流でESP32が再起動しないよう、別の5V電源を使います。

角度を受け取る入口を1つにする

applyAngleCommand(String text)へ文字列を渡せば、シリアル入力でもWebSocketでも同じ安全チェックとサーボ制御を使えます。入力方法と動作を分ける設計です。

シリアル入力 ─┐
              ├→ applyAngleCommand() → servo.write()
WebSocket ────┘

安全範囲はソフトウェアでも守る

constrain(angle, 30, 150)によって、999が届いても150°へ丸めます。機構側のストッパーと合わせ、二重に安全を作ります。

回路 → 自動往復 → シリアル命令 → 入力チェック → ファイル保存の順で、出力側を完成させます。

T23WokwiでESP32とサーボを配線する

  1. WokwiでESP32プロジェクトを作る。
  2. 部品追加からServoを置く。
  3. 信号線をGPIO 13、電源をVIN/5V、GNDをGNDへつなぐ。
シミュレータと実機の違いこの配線はWokwi上の確認用です。実物のサーボはESP32から直接給電せず、フェーズ5の外部5V配線を使います。
完了の確認画面上でESP32とサーボの3本の線が正しいピンへ接続されている。

T24サーボを安全範囲で往復させる

#include <ESP32Servo.h>

Servo testServo;
const int SERVO_PIN = 13;

void setup() {
  testServo.setPeriodHertz(50);
  testServo.attach(SERVO_PIN, 500, 2400);
}

void loop() {
  for (int angle = 30; angle <= 150; angle++) {
    testServo.write(angle);
    delay(20);
  }
}
Arduinoの2つの関数setup()は起動時に1回、loop()は電源が入っている間ずっと繰り返されます。forは角度を1ずつ増やす反復処理です。
完了の確認再生するとサーボが30°〜150°を往復する。

T25シリアルから角度を受け取る

if (Serial.available() > 0) {
  String command = Serial.readStringUntil('\n');
  command.trim();
  applyAngleCommand(command);
}
シリアル通信USBケーブルを通してPCとESP32が文字を送受信します。'\n'はEnterで付く改行文字です。
完了の確認シリアルモニタへ120と送ると、サーボが120°へ動く。

T26おかしな入力と危険な角度を防ぐ

int angle = text.toInt();
angle = constrain(angle, 30, 150);
myServo.write(angle);

実装では変換前に各文字が数字かどうかも確認し、数字でない場合はエラーを表示して終了します。

完了の確認abcは無視され、999は150°、-20は30°へ制限される。

T27実機用スケッチとして保存する

Wokwiで確認したコードを、Arduino IDEが認識するスケッチフォルダへ保存します。

esp32/
└── looking_animal/
    ├── looking_animal.ino
    └── secrets.h
スケッチフォルダArduino IDEでは、フォルダ名とメインの.inoファイル名を同じにします。関連するsecrets.hも同じフォルダへ置きます。
完了の確認esp32/looking_animal/looking_animal.inoとしてリポジトリに保存されている。
