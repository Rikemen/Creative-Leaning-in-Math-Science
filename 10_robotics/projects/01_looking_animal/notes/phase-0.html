Phase 0 — ブラウザとカメラの準備

このフェーズでは「描く場所」と「映像の入口」を作ります。カメラ映像を表示できれば、次のフェーズで顔認識を重ねられます。

ESP32 不要目安 40分DEVLOG 完了

p5.jsは、毎フレーム絵を描く

p5.jsでは、最初に一度だけ動くsetup()と、1秒間に何十回も繰り返すdraw()を使います。キャンバスはロボットの視界と状態を見せる「モニター」です。

setup()

画面サイズやカメラなど、最初に一度だけ必要な準備をします。

draw()

背景、映像、顔の枠、仮想の首を毎フレーム描き直します。

なぜローカルサーバーが必要？

ブラウザはカメラをプライバシーに関わる機能として扱います。HTMLをファイルとして直接開くfile://ではなく、安全な開発元として扱われるhttp://localhostから開きます。

URLの意味localhostは「いま使っている自分のPC」を表す特別な名前です。インターネットへ公開するわけではありません。

鏡表示と座標の違い

カメラの生映像は、画面を見ている自分には左右が逆に感じられます。そこで描画するときだけX方向を反転します。ただし、顔認識が返す座標は元映像の座標なので、次のフェーズでも左右を合わせる計算が必要です。

作業対象はpc/index.htmlとpc/sketch.jsです。1タスクごとに画面を確認し、動いた状態を残してから次へ進みます。

T01p5.jsのキャンバスを表示する

index.htmlでp5.jsとsketch.jsを読み込み、JavaScript側で640×480の描画領域を作ります。

sketch.jsの最小構成

function setup() {
  createCanvas(640, 480);
}

function draw() {
  background(40, 120, 160);
}
構文の読み方function setup() { ... }は「setupという処理のまとまりを定義する」という意味です。丸かっこは入力、波かっこは実行内容を表します。
完了の確認ブラウザに640×480の青い四角が表示される。

T02ローカルサーバーで開く

ターミナルを10_robotics/で開き、次を実行します。

cd projects/01_looking_animal/pc
python3 -m http.server 8000

Chromeでhttp://localhost:8000を開きます。停止するときはターミナルでControl + Cを押します。

コマンドの読み方cdは作業場所の移動、python3 -m http.server 8000は8000番の入口で簡易Webサーバーを起動する命令です。
完了の確認アドレス欄がlocalhost:8000の状態で、T01と同じキャンバスが表示される。

T03Webカメラの映像を表示する

createCapture(VIDEO)でブラウザへカメラ映像を要求し、p5.jsのキャンバスへ描きます。

let capture;

function setup() {
  createCanvas(640, 480);
  capture = createCapture(VIDEO);
  capture.size(640, 480);
  capture.hide();
}

function draw() {
  image(capture, 0, 0, width, height);
}
変数と引数captureは取得した映像を覚えておく箱です。image()の丸かっこ内は、順に「描く映像・X座標・Y座標・幅・高さ」です。
完了の確認カメラ利用を許可すると、自分の映像がキャンバス内に表示される。

T04映像を鏡のように左右反転する

座標系を右端へ移動してから、X方向を-1倍します。push()とpop()で、この変換がほかの絵へ影響しないよう囲みます。

push();
translate(width, 0);
scale(-1, 1);
image(capture, 0, 0, width, height);
pop();
ハードウェアとの関係いまは映像だけの調整ですが、この左右方向が後でサーボの30°〜150°へ対応します。ここで直感に合う向きにしておくことが重要です。
完了の確認右手を挙げると、画面の右側に見える手が上がる。
