Phase 1 — MediaPipeで顔を見る

顔認識の結果は「顔」という言葉ではなく、画像のどこに顔があるかを示す四角形です。その四角形を、首を動かすための数値へ変換します。

MediaPipe正規化 0〜1DEVLOG 完了

FaceDetectorが返すもの

boundingBoxには、四角形の左上座標originX・originYと、width・heightが入ります。顔の中心X座標は次の考え方です。

中心X = originX + width / 2
0〜1の位置 = 中心X / 映像の幅

640pxの映像で中心Xが320pxなら、320 / 640 = 0.5です。映像サイズが変わっても同じ0〜1で扱えることを「正規化」と呼びます。

反転した画面との向きを合わせる

顔認識は反転前の映像座標を返します。画面は鏡表示なので、そのままでは左右が逆です。そこで1 - rawCenterXとし、画面で見えている方向へ合わせます。

生の座標 0.2

カメラ元映像では左寄り。鏡表示では右側に見えます。

反転後 1 - 0.2

0.8となり、画面の右寄りという見た目と一致します。

複数人なら「一番大きい顔」を見る

顔の四角形の面積width × heightを比べます。最も大きな顔は、一般にはカメラへ最も近い人です。これは完璧な距離計ではありませんが、展示で「目の前の人を見る」ための分かりやすい規則です。

MediaPipeの準備は非同期です。読み込みが終わるまでは検出を行わず、準備完了後だけ毎フレーム顔を探します。

T05MediaPipe FaceDetectorを読み込む

JavaScript本体とWASMを同じバージョンに固定し、近距離向けの顔検出モデルを準備します。

import { FaceDetector, FilesetResolver }
  from "https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@0.10.21/vision_bundle.mjs";

const vision = await FilesetResolver.forVisionTasks(
  "https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@0.10.21/wasm"
);

faceDetector = await FaceDetector.createFromOptions(vision, {
  baseOptions: { modelAssetPath: MODEL_URL, delegate: "GPU" },
  runningMode: "VIDEO"
});
構文の読み方importは外部の道具を読み込む命令、awaitは読み込み完了まで待つ命令です。WASMはブラウザ内で高速に計算するための形式です。
完了の確認Consoleに「MediaPipe FaceDetector の準備が完了しました！」と表示される。

T06顔を検出して枠を描く

動画の現在フレームと時刻を検出器へ渡します。検出器がまだ無い場合は空配列を使い、画面を止めません。

const detections = faceDetector
  ? faceDetector.detectForVideo(
      capture.elt,
      performance.now()
    ).detections
  : [];

for (const detection of detections) {
  const box = detection.boundingBox;
  rect(box.originX, box.originY, box.width, box.height);
}
条件演算子条件 ? A : Bは、条件が正しければA、違えばBを使う短いif文です。初期化中のエラーを防ぎます。
完了の確認顔を動かしても、四角い枠が追いかけてくる。

T07顔の中心X座標を0〜1で取り出す

function toScreenNormalizedCenterX(box, videoWidth) {
  const rawCenterX =
    (box.originX + box.width / 2) / videoWidth;
  return 1 - rawCenterX;
}
関数の入力と出力boxとvideoWidthが入力です。returnは計算結果を呼び出し元へ返します。この関数の出力は常におよそ0〜1です。
完了の確認画面上で左へ動くと値が0へ、右へ動くと1へ近づく。

T08複数人から1人を選ぶ

function selectTargetFace(detections) {
  if (!detections || detections.length === 0) return null;

  return detections.reduce((largest, current) => {
    const largestArea = largest.boundingBox.width
      * largest.boundingBox.height;
    const currentArea = current.boundingBox.width
      * current.boundingBox.height;
    return currentArea > largestArea ? current : largest;
  });
}
reduce()の役割配列を先頭から比べ、これまでで最大の顔をlargestとして残します。最後に1つの顔だけが返ります。
完了の確認2人映ると近い人の枠が赤、ほかの顔の枠が緑になる。

T09「人がいない」を判定する

対象の顔が無いときは数値の代わりにnullを使います。0は画面左端という有効な位置なので、「いない」の印には使えません。

if (targetFace) {
  targetX = toScreenNormalizedCenterX(
    targetFace.boundingBox,
    capture.elt.videoWidth
  );
} else {
  targetX = null;
}
完了の確認カメラから離れると、画面表示が「誰もいない」へ切り替わる。
