Phase 3 — WebSocketで角度を送る

WebSocketは、ブラウザとESP32の間に開いたままの通信路を作ります。毎回手紙を出すHTTPより、細かい角度を続けて送る用途に向いています。

ESP32 不要Port 81DEVLOG 完了

ブラウザは「クライアント」、ESP32は「サーバー」

ブラウザからESP32のIPアドレスへ接続します。この段階ではESP32の代わりにNode.jsのmock-serverを使い、送った角度が届くかだけを確認します。

  1. 🧠p5.js
    角度を決定
  2. 🔢整数化
    90など
  3. ⏱️50ms間隔
    間引く
  4. 📡WebSocket
    文字列送信
  5. 🖥️代役
    受信表示

送りすぎない2つの工夫

同じ角度は送らない

前回の整数角度を覚え、変化が無ければ送信を終了します。

50ms以上空ける

最大でも1秒に20回へ制限し、受信側の処理が詰まるのを防ぎます。

切断は「失敗」ではなく状態

Wi-Fiでは切断が起こり得ます。接続中だけ送信し、切断したら3秒後に再接続します。例外で画面全体を止めず、「🔴 切断」と状態を見せる設計が大切です。

最初はConsole出力、次に代役サーバー、最後に再接続という順で、1つずつ通信の責任を増やします。

T17送る角度を決める

const roundedAngle = Math.round(angle);
if (roundedAngle === lastSentAngle) return;

console.log(`Sending angle: ${roundedAngle}`);
lastSentAngle = roundedAngle;
早期return条件に当てはまったら関数を途中で終える書き方です。不要な処理を下へ流さず、読みやすくできます。
完了の確認首が動く間だけConsoleへ整数が出て、止まると出力も止まる。

T18送信間隔を50ms以上にする

if (p.millis() - lastSentTime < 50) return;

lastSentTime = p.millis();
頻度の計算1000ms ÷ 50ms = 20なので、最大20回/秒です。画面描画が60回/秒でも通信量を抑えられます。
完了の確認Consoleの角度出力が1秒に20回以下になる。

T19代役WebSocketサーバーを起動する

cd projects/01_looking_animal/pc/mock-server
npm install
node server.js

サーバー側は接続とメッセージのイベントを待ちます。

const WebSocket = require("ws");
const wss = new WebSocket.Server({ port: 81 });

wss.on("connection", (ws) => {
  ws.on("message", (message) => {
    console.log(`Received angle: ${message}`);
  });
});
完了の確認Mock WebSocket server is running on ws://localhost:81と表示される。

T20p5.jsから代役へ送る

const socket = new WebSocket("ws://localhost:81");

if (socket.readyState === WebSocket.OPEN) {
  socket.send(String(roundedAngle));
}
なぜ文字列？角度をString()で「90」というテキストへ変えます。人間にも読め、ESP32側でも整数へ変換しやすい形式です。
完了の確認顔を動かすと、代役サーバーのターミナルへ角度が表示される。

T21切断しても壊れないようにする

function setupWebSocket() {
  socket = new WebSocket(WEBSOCKET_URL);

  socket.onclose = () => {
    setTimeout(setupWebSocket, 3000);
  };
}
コールバックoncloseへ関数を渡すと、切断が起きたときブラウザがその関数を呼びます。setTimeoutで3秒待ってから接続し直します。
完了の確認サーバー停止で「切断」、再起動から最大3秒ほどで「接続中」へ戻る。

T22接続先を1か所にまとめる

const WEBSOCKET_URL = "ws://localhost:81";

// 実機では次の形に変更
// const WEBSOCKET_URL = "ws://192.168.x.x:81";
定数にする利点URLをコードの何か所にも直接書くと変更漏れが起きます。先頭の定数1つだけを変えれば、代役と実機を切り替えられます。
完了の確認WEBSOCKET_URLの1行だけで接続先を変更できる。
