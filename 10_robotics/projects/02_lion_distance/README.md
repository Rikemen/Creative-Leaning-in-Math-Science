# 距離によって態度が変わるライオン (Project 002)

## 概要
ESP32と距離センサーを用いて、来場者との「距離」に応じて態度が変わるライオンのアニマトロニクスを作成します。

## 状態定義
- **SLEEPING** (遠距離: 2m〜): 寝ている状態
- **ALERT** (中距離: 1m〜2m): 起きて警戒する状態
- **ROARING** (近距離: 〜1m): 威嚇・咆哮する状態

## 構成
- **ハードウェア**: ESP32, 距離センサー(超音波または赤外線), サーボモーター
- **ソフトウェア(PC)**: p5.jsによる状態描画と音声再生
- **通信**: WebSocket (ESP32 -> PC)

## 起動方法 (PCモック)
1. `pc/mock-server` ディレクトリで `npm install` を実行
2. `node server.js` を実行してモックサーバーを起動
3. ブラウザで `pc/index.html` を開く

## シミュレーション (ESP32)
ESP32のコードは、VSCode拡張機能ではなく**ブラウザ版のWokwi (https://wokwi.com/)** を用いて検証します。
新規のESP32プロジェクトを作成し、`esp32/lion_distance/lion_distance.ino` の内容を貼り付けて回路を構築してください。
