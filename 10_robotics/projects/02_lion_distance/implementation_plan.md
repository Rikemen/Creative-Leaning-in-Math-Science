# 実装計画：距離によって態度が変わるライオン (Project 002)

## 1. 目的
来場者との「距離」に応じて態度（状態）を変えるインタラクティブな人工生物（ライオン）を制作する。
最終的には実機の距離センサー（赤外線または超音波）を用いて ESP32 側で距離を測定・状態判定し、サーボモーターを動かすと同時に、PC側に状態を送信して鳴き声（音声）を再生させる。

## 2. 分析（現状分析）
- **状態定義:**
  - **遠距離（例: 2m以上）** → `SLEEPING`（寝ている、首が下がっている）
  - **中距離（例: 1m〜2m）** → `ALERT`（警戒、首を上げてこちらを見る）
  - **近距離（例: 1m未満）** → `ROARING`（威嚇/吠える、口が開く、PCから咆哮音が鳴る）
- **ハードウェア（実機導入後）:**
  - ESP32 が「センサーの読み取り」「状態遷移の決定」「サーボの制御」「PCへの状態送信（WebSocket）」の全て（脳と体）を担う。
- **シミュレーション環境（実機到着前）:**
  - Wokwi 上で「超音波センサー（HC-SR04）」部品を使って仮想的に距離入力をシミュレートする。
  - PC側（p5.js）単体でのテスト用に、ランダムな状態変化を送信する「モックサーバー」を用意する。

## 4. 実装の進め方（フェーズ分け）

### フェーズ1：PC側（UIと音声）のモック開発
ESP32がなくても進められる、ブラウザ側の演出を作り込みます。
1. `pc/` フォルダ内のファイルを作成。
2. p5.js で `SLEEPING`, `ALERT`, `ROARING` の3つの状態を描画（文字や色、簡単なイラスト）。
3. `p5.sound` を用いて、`ROARING` 状態になった瞬間にライオンの鳴き声（mp3）を再生するロジックを実装。
4. `mock-server/server.js` を作成し、定期的にダミーの状態データをブラウザに送信してテストする。

### フェーズ2：ESP32側（センサーと状態遷移）のシミュレーション開発
ブラウザ版の Wokwi (https://wokwi.com) を使って、実機と同等の C++ プログラムを作成します。VSCode拡張機能はビルド環境の依存等でエラーになるリスクがあるため、今後のシミュレーション開発はブラウザ版を前提とします。
1. `lion_distance.ino` に距離を測るロジック（超音波センサー等）を実装。
2. `switch` 文等を用いたステートマシン（状態機械）を実装し、距離に応じた状態遷移のロジックを作成。
3. 状態に合わせてサーボを動かす（例：首用サーボ、口用サーボ）。
4. 現在の状態を `SLEEPING` などの文字列として WebSocket でブロードキャスト（送信）するロジックを追加。

### フェーズ3：実機への適用（実機到着後）
1. 実際の ESP32 と赤外線/超音波距離センサー、サーボモーターを配線。
2. `lion_distance.ino` を書き込み。
3. 実機の前を人が歩いたときに、PCから音が鳴り、サーボが動くことを確認。

## 5. リスク評価と注意点
- **センサーのノイズ:** 距離センサー（特に赤外線や超音波）は値がブレやすいため、1回の異常値ですぐに状態が変わらないよう、プログラム側で「移動平均」や「〇回連続で近かったら」といったフィルタリング処理を入れる必要があります。
- **音声の多重再生:** `ROARING` 状態の間、毎フレーム音声再生コマンドが走って音が重なる（バグる）のを防ぐため、「状態が変わった瞬間だけ音を鳴らす（エッジ検出）」ロジックが必須です。
- **ブラウザの音声再生制限:** 現代のブラウザは「ユーザーが一度画面をクリックする」まで音声を再生できない仕様になっています。最初に「Start」ボタンを押させるようなUI設計が必要です。
