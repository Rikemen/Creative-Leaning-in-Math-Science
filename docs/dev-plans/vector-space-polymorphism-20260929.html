Vector Space Polymorphism

ベクトル空間におけるポリモーフィズムの実装計画

概要

「作って学ぶ数学」のコンセプトに基づき、ベクトル空間の「一般化された対象に対して同じ定理・操作が適用できる」という抽象化の威力を、プログラミングのポリモーフィズム（多態性）を用いて証明・体感するための実装計画です。

💡 期待される学習効果:
行列や多項式といった全く異なるデータ構造を持つオブジェクトに対して、同一の calculateLinearCombination（線形結合）関数が動作することを確認することで、ベクトル空間の公理に基づく抽象化のメリットを直感的に理解します。

Phase 1: 基礎クラスの整備

ベクトル空間の要素が満たすべき共通のインターフェース（親クラス）を定義し、既存の行列クラスを適応させます。

ステータス タスクID タスク内容 (約15分) 具体的な実装内容 ＆ 確認手順
Task 1.1 VectorSpaceElement の作成 Matrix.js（または別ファイル）に親クラスを作成し、add(other) と multScalar(scalar) メソッドを未実装（throw Error）として定義する。
Task 1.2 Matrix クラスの継承対応 既存の Matrix クラスを extends VectorSpaceElement に変更する。
※既存の加法とスカラー倍のメソッド名を add と multScalar に統一・調整する。
コミット境界: Phase 1 完了後に「refactor: define VectorSpaceElement and apply to Matrix」としてコミットする。

Phase 2: 拡張と汎用性の証明

全く異なるベクトル（多項式）を実装し、それらを統一的に扱う関数を作成します。

ステータス タスクID タスク内容 (約15分) 具体的な実装内容 ＆ 確認手順
Task 2.1 Polynomial クラスの実装 VectorSpaceElement を継承した Polynomial（1変数多項式）クラスを作成する。配列で係数を管理し、add と multScalar を多項式用に実装する。
Task 2.2 汎用関数の実装 引数に VectorSpaceElement を取る汎用関数 calculateLinearCombination(v1, v2, a, b) を実装し、内部で v1.multScalar(a).add(v2.multScalar(b)) を返すようにする。
コミット境界: Phase 2 完了後に「feat: implement Polynomial and generic linear combination function」としてコミットする。
