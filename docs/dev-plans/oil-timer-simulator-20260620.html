Oil Timer Simulator Development Plan

p5.js と WEBGL シェーダ表現を組み合わせ、幻想的な oil timer 風シミュレーターを 8_arts/oil-timer に実装するための計画。

0概要

目的: 既存の最小 p5.js スケッチを、縦型オイルタイマーのような液滴運動、発光、反射、粒子、WEBGL 背景を備えた鑑賞型インタラクティブ作品に作り替える。

完成イメージ

  • 中央に透明なガラス容器があり、上下にゆっくり流れる複数色の油滴が見える。
  • 液滴はメタボール風に近づくと融合し、離れると分裂したように見える。
  • 背景は p5.js の WEBGL グラフィックスバッファで生成する淡いノイズ・星雲・屈折風の光。
  • クリックまたはタップで重力反転、ドラッグで液滴を攪拌できる。
  • 静かな鑑賞用として、UIは最小限に抑え、画面全体で成立する。

対象ファイル

  • 8_arts/oil-timer/index.html: p5.js 読み込み、ページメタ情報、最小CSS。
  • 8_arts/oil-timer/sketch.js: 描画、シミュレーション、インタラクション。
  • 8_arts/oil-timer/解説.md: 操作方法、設計意図、主要パラメータの説明。

2Phase 2: 液滴シミュレーション

ステータスタスクIDタスク内容具体的な実装内容 & 確認手順
Task 2.1液滴クラス設計OilDrop に位置、速度、半径、色、浮力、粘性、位相を持たせる。確認: 複数液滴が個別に動く。
Task 2.2容器内境界処理楕円またはカプセル型容器内に液滴を閉じ込め、壁面で滑るように反射する。確認: 液滴が画面外や容器外へ抜けない。
Task 2.3浮力と粘性の実装色ごとに上昇・下降傾向を分け、速度に減衰をかけて油らしい遅さにする。確認: 急加速せず、ゆっくり沈降・浮上する。
Task 2.4疑似融合表現距離が近い液滴間にブリッジ状の半透明楕円や曲線を描き、メタボール風に見せる。確認: 近接時に自然につながって見える。
Task 2.5泡と微粒子小さな泡粒子を追加し、液滴の近くで速度や透明度が変化するようにする。確認: 主役を邪魔せず奥行きが出る。

6開発の進め方ルール

コミット境界: 計画作成と実装は分ける。今回の計画ファイル追加とは別に、実装時は 8_arts/oil-timer の3ファイルを中心に差分を限定する。
  • p5.js CDN 以外の外部ライブラリは追加しない。シェーダも sketch.js 内に文字列として持つ。
  • WEBGL が動作しない場合でも、2D背景で作品が見えるフォールバックを用意する。
  • フレームごとに大量のオブジェクトを生成しない。配列は初期化時に作り、更新で使い回す。
  • モバイル操作ではスクロールやズームが誤発火しないよう touchMoved の扱いを確認する。
  • 実装後は file:// で開く運用を前提に、ビルド工程を追加しない。
