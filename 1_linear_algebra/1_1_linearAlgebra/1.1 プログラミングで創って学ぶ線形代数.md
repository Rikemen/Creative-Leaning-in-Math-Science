## 🚀 なぜ線形代数を学ぶのか？

「線形代数（Linear Algebra）」は、現代のデジタルテクノロジー・ものづくり・サイエンスにおいて **最も強力な共通言語** です。

### 1. コンピュータグラフィックス（CG） & ゲーム開発
3Dキャラクターの移動・回転・拡大縮小、カメラの視点切り替え、光と影のレンダリング（シェーダー処理）など、**画面に映るすべての映像表現の根底には行列とベクトルが存在します**。

### 2. AI・機械学習・データサイエンス
画像認識、自然言語処理（ChatGPTなどのLLM）、レコメンデーションシステムなど、AIはあらゆるデータを「多次元ベクトル」として数値化し、膨大な行列の演算を行うことで推論や学習を実現しています。

### 3. 物理シミュレーション & ロボティクス
重力や空気抵抗による物体の落下、剛体の衝突、流体のシミュレーション、ロボットアームの関節角度制御など、**現実世界の物理現象をシミュレートして操るための必須ツール** です。

### 4. 「空間」と「データ」を自在に操る万能ツール
一見バラバラに見える大量のデータや複雑な連立方程式も、行列とベクトルの形式に落とし込むことで、コンピュータが最も得意とする高速な一括処理が可能になります。

教科書に載っている数学は、無駄が削ぎ落とされた「完成された体系」として提示されます。しかし、その綺麗さゆえに、**「先人たちがなぜその概念を思いつき、なぜその記号やルールで定義したのか」** という最も面白い試行錯誤のプロセスが見えにくくなっています。

本シリーズで「プログラミングを通して数学を自ら創る」ことには、次のような深い意義とメリットがあります：

### 1. 数学が数学になる手前の段階（前数学）を追体験できる
- **「なぜそもそも、そんな概念を考え出す必要があったのか？」**
- **「なぜその名前を付け、その記号で定義したのか？」**
完成した数式を天下り式に受け取るのではなく、「画面上の複数の位置をスッキリ扱いたい」「図形を一括で回転・移動させたい」という**切実な動機・課題**からスタートします。自分の手でコードとして組み立てることで、数学が体系化される手前（前数学）の思考プロセスをリアルに体験できます。

### 2. 「なぜこのように定式化するのか？」の理由に近づける
数学の概念には、歴史的にも本来多様な定式化（表現方法）の選択肢があったはずです。
- **「なぜ他の表現ではなく、この形式で定式化されたのか？」**

### 3. 直感（幾何学）と形式（数式）の融合
- **「ベクトルを足す」 ＝ 物体がその方向に移動する**
- **「行列を掛ける」 ＝ 空間そのものが回転したり、拡大・せん断変形する**
p5.js で実際にコードを書き、リアルタイムに画面を動かすことで、抽象的な記号の並びが「生きた操作」へと変わり、直感と数式が無理なく結びつきます。

## 🎨 なぜ「画面描画」から始めるのか？

線形代数の根幹をなす **「ベクトル（Vector）」** は、代数的には数の組ですが、幾何学的には **「空間内の位置」** や **「向きと大きさを持つ矢印」** です。

$$\vec{p} = \begin{pmatrix} x \\ y \end{pmatrix}$$

プログラム上でキャンバスを作成し、2次元ベクトルを用いて位置を指定して図形を描画することで、数式と幾何学的イメージをダイレクトに結びつけることができます。

### 2. キャンバスを作成して直接座標を指定して描画する

まずは `setup()` でキャンバスを生成し、`draw()` 内で背景色や円を描画する基本コードです。

```javascript
function setup() {
    // 幅800px、高さ400pxのキャンバスを生成
    createCanvas(800, 400);
}

function draw() {
    // 背景色（水色系: RGB(176, 224, 230)）
    background(176, 224, 230);
    
    // 輪郭線の色（黒）
    stroke(0);
    
    // 塗りつぶしの色（淡い黄色系: RGB(255, 255, 224)）
    fill(255, 255, 224);
    
    // x=400, y=200 の位置に、直径30pxの円を描画
    ellipse(400, 200, 30, 30);
}
```

#### 📌 ポイント
- **`setup()`**: プログラム起動時に1度だけ実行されます。キャンバスの初期化などに使います。
- **`draw()`**: 毎フレーム（通常1秒間に60回）繰り返し実行される描画ループです。
- **コンピュータの画面座標系**: 
  - 数学の一般的なデカルト座標系と異なり、**画面の左上が原点 $(0, 0)$** です。
  - **右方向が $x$ の正方向**、**下方向が $y$ の正方向** となります。

---

### 3. 2次元ベクトル（`createVector`）を使って位置を表現する

直接数値を書き込むのではなく、位置を **2次元ベクトル `pos`** として定義して管理します。

```javascript
let pos;    // 位置ベクトルを保持する変数
let radius; // 円の半径/直径を保持する変数

function setup() {
    createCanvas(800, 400);
    
    // 2次元ベクトルを作成: pos = (400, 200)
    pos = createVector(400, 200);
    radius = 30;
}

function draw() {
    background(176, 224, 230);
    fill(255, 255, 224);
    stroke(0);
    
    // ベクトルのx成分、y成分を使って円を描画
    ellipse(pos.x, pos.y, radius, radius);
}
```

#### 📌 ベクトル化するメリット
1. **成分の統合管理**: $x$ と $y$ の座標を別々の変数（`x`, `y`）で管理するのではなく、1つのベクトルオブジェクト `pos` としてひとまとめに扱えます。
2. **数学的操作への拡張性**: 今後学ぶ「ベクトルの足し算（移動）」「スカラー倍（拡大縮小）」「行列による線形変換（回転やせん断）」などを、ベクトルの演算メソッドを使って簡潔に記述できるようになります。

---

## 📝 まとめ

- `createCanvas(width, height)` で描画領域を作成する
- `ellipse(x, y, w, h)` や `point(x, y)` で図形・点を描く
- `createVector(x, y)` を使うことで、2次元の位置を **ベクトル** として直感的に操作できる土台が完成する

次回以降は、このベクトルに対して **演算（加算・スカラー倍）** や **行列との掛け算（線形変換）** を適用し、画面上の図形や点がどのように変化するかを学んでいきます。
