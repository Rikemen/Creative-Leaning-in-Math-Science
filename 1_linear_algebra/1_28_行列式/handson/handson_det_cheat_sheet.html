理論
余因子展開とは何か、なぜ成り立つのか

① 余因子展開（Laplace Expansion）の定義

n×n 行列 A の行列式は、任意の1行（ここでは第1行）を固定して次のように表せます。

det(A) = Σj=1..n (-1)1+j · a1j · det(M1j)
Σ：1行目の各要素に対して合計
(-1)1+j：市松模様状の符号（+ - + - ...）
a1j：1行目 j列目の要素
M1j：A から1行目と j列目を取り除いた (n-1)×(n-1) 小行列（Minor）

② 行列式の「多重線形性（Multilinearity）」

行列式には2つの重要な性質があります。これが余因子展開の根拠になります。

性質1: 各行について線形（多重線形性）
ある行を定数倍したり足したりしても、行列式はその行について線形に変化します。
つまり、行の中身を「ベクトルの和」に分解すれば、行列式も分解できます。
性質2: 交代性（Alternating）
2行を入れ替えると符号が反転します。
同じ行が2行あると det = 0 になる（面積が潰れる）のも、この性質の帰結です。

③ 余因子展開が成り立つ理由（証明の骨格）

Step A: 第1行を基底ベクトルに分解する
行列 A の第1行 (a11, a12, ..., a1n) を、標準基底ベクトル ej の線形結合で表します。
第1行 = a11·e1 + a12·e2 + ... + a1n·en
Step B: 多重線形性で det を分解する
det は各行に対して線形なので、Step A の分解を代入することで det を n 個の項の和に分解できます。
det(A) = a11·det(A|第1行 = e1) + a12·det(A|第1行 = e2) + ... + a1n·det(A|第1行 = en)
Step C: 各項の det を「小行列の det」に帰着させる
「第1行が ej だけの行列」の行列式は、行の交換（交代性）を使って ej を1行目に移動することで評価できます。
ej を1列目まで移動するには (j-1) 回の列交換が必要 → 符号は (-1)j-1 = (-1)1+j 倍
残った (n-1)×(n-1) のブロックが、そのまま det(M1j) になります。
✅ 結論：3つを掛け合わせると余因子展開の公式になる
det(A) = Σ (-1)1+j · a1j · det(M1j)
符号 (-1)1+j は「ej を左上に移動するのに必要な行交換の回数」から来ており、
小行列式 det(M1j) は「残ったブロックの行列式」から来ています。
この構造が、コードの再帰とそのまま一致します。

④ 証明の各パーツとコードの1対1対応

for (j = 0; j < n; j++) {                                ← Σ（Step B の和）
  element = this.data[0][j];                           ← a1j
  sign = (-1)^j;                                        ← (-1)1+j（Step C の列交換回数）
  subMatrix = getSubMatrix(0, j);                   ← M1j（1行と j 列を除いた小行列）
  det += sign * element * subMatrix.determinant(); ← det(M1j) を再帰で計算（Step C）
}

Step 3
小行列生成（getSubMatrix）の実装

🎙️ トーク意図・スクリプト

  • 「じゃあ3x3以上はどうする？サラスの公式を書く？いや、どんな次元でも計算できるように余因子展開を使おう」と提案します。
  • 余因子展開には「自分自身の行と列を消した、一段階小さい行列（小行列）」が必要になるため、それを生成するヘルパー関数 getSubMatrix を作ります。
  • ※このメソッドは determinant() の上に定義します。
/**
 * 指定した行と列を除外した小行列（Minor Matrix）を生成します。
 */
getSubMatrix(excludeRow, excludeCol) {
    // 1サイズ小さい行列を作成
    let subMatrix = new Matrix(this.rows - 1, this.cols - 1);
    let subRow = 0;

    for (let i = 0; i < this.rows; i++) {
        if (i === excludeRow) continue; // 指定行はスキップ

        let subCol = 0;
        for (let j = 0; j < this.cols; j++) {
            if (j === excludeCol) continue; // 指定列はスキップ

            subMatrix.data[subRow][subCol] = this.data[i][j];
            subCol++;
        }
        subRow++;
    }
    return subMatrix;
}
Step 4
再帰呼び出し（余因子展開）の完成

🎙️ トーク意図・スクリプト

  • 1行目（i=0）を基準にループを回し、「要素 × 符号 × 小行列の行列式」を足し合わせます。
  • ここで subMatrix.determinant() と「自分自身を呼び出す（再帰）」部分が最大のハイライトです。

数式とコードの完全一致（ここを熱く語る！）

det(A) = Σ (-1)^(1+j) * a_1j * det(M_1j)

Σ (総和) ➔ for (j=0...) { det += ... }
(-1)^(1+j) ➔ let sign = ...
a_1j (要素) ➔ let element = this.data[0][j]
det(M_1j) ➔ subMatrix.determinant()

再帰のイメージ図（3x3の場合）

※ 3x3の計算が、3つの2x2の計算に分解され、それぞれの2x2はベースケース（ad-bc）に到達して値が返っていく様子を図でイメージさせます。

▼ 具体的な実行トレースを開く（3x3行列の例） 
    // ... determinant() の末尾に追加

    // 4. 3x3以上の行列の場合（1行目を基準に余因子展開）
    let det = 0;
    
    // 1行目のすべての列(j)に対してループ
    for (let j = 0; j < this.cols; j++) {
        let element = this.data[0][j];
        
        // 対象の要素を含む行(0)と列(j)を除外した小行列を取得
        let subMatrix = this.getSubMatrix(0, j);
        
        // 符号： (-1) の (i+j) 乗。今回は i=0 なので j が偶数なら +, 奇数なら -
        let sign = (j % 2 === 0) ? 1 : -1;
        
        // ★魔法の再帰！ 小行列の行列式を計算して足す
        det += sign * element * subMatrix.determinant();
    }

    return det;

深掘り
4x4 行列で再帰呼び出しの全体像を追う

4x4の場合、det += sign * element * subMatrix.determinant() の subMatrix.determinant() の中で、 また同じコードが走ります。つまり 「4x4 → 3x3 → 2x2 → 終了」という3段階の入れ子呼び出しが発生します。

  det += sign * element * subMatrix.determinant();
                                    ↑ ここで 3x3 の計算を再帰的に依頼！

🔢 合計で determinant() が何回呼ばれるか？
4x4: 1 回
  └─ 3x3 を呼ぶ × 4 = 4 回
       └─ 2x2 を呼ぶ × 3 × 4 = 12 回

合計 1 + 4 + 12 = 17 回 の determinant() が呼び出される。
（n×n の場合は O(n!) 回になる。これが「可読性重視で大規模計算には不向き」な理由）
