### API と使い方

数学の番号に合わせて入力は **1〜n** とします。配列 `[2, 3, 1]` は、1→2、2→3、3→1 という対応です。

```js
const sigma = new Permutation([2, 3, 1]);
const sigmaFunction = (i) => sigma.apply(i);
sigmaFunction(1); // 2：数学の σ(1) に対応
sigma.size;       // 3（読み取り専用）
sigma.toArray();  // [2, 3, 1]（コピー）
```

| 操作 | API | 結果の例 |
| --- | --- | --- |
| 恒等置換 | `Permutation.identity(3)` | `[1, 2, 3]` |
| 合成 | `alpha.compose(beta)` | 下記参照 |
| 逆置換 | `sigma.inverse()` | `[3, 1, 2]` |
| 巡回置換 | `Permutation.cycle(4, [1, 3, 2])` | `[3, 1, 2, 4]` |
| 互換 | `Permutation.transposition(4, 1, 3)` | `[3, 2, 1, 4]` |
| 符号 | `sigma.sign()` | `1` |
| 偶置換か | `sigma.isEven()` | `true` |
| 奇置換か | `sigma.isOdd()` | `false` |

置換を生成する操作は `Permutation` を返します。表の配列は `.toArray()` で確認できます。合成・逆置換は元の置換を変更しません。

**合成は右側から先に作用します。** `alpha.compose(beta)` は α∘β、つまり `alpha.apply(beta.apply(i))` です。

```js
const alpha = new Permutation([2, 1, 3]);
const beta = new Permutation([1, 3, 2]);
alpha.compose(beta).toArray(); // [2, 3, 1]：β → α
beta.compose(alpha).toArray(); // [3, 1, 2]：α → β
sigma.compose(sigma.inverse()).toArray(); // [1, 2, 3]
```

巡回 `(1 3 2)` は 1→3→2→1 を表し、指定外の4は固定します。互換 `(1 3)` は1と3だけを交換します。

符号は **転倒数** で計算します。`i < j` なのに `σ(i) > σ(j)` となる組の数を I とすると、`sgn σ = (-1)^I` です。`[2, 3, 1]` では値の組 `(2, 1)` と `(3, 1)` が転倒なので I=2、符号は +1 です。符号 +1 は偶置換、-1 は奇置換になります。

### 入力の約束

- 次数 n は1以上の整数です。この教材では空の置換を扱いません。
- 対応配列には1〜nを重複なく含めます。疎配列も拒否します。
- 合成する置換は同じ次数である必要があります。
- 巡回の要素は1個以上、重複なしです。1要素の巡回は恒等置換になります。
- 互換の2要素は異なる必要があります。
- 型の不一致は `TypeError`、範囲外・非整数・重複などは `RangeError` になります。
- 入力配列と `toArray()` の返却配列を書き換えても、置換内部の対応は変わりません。
