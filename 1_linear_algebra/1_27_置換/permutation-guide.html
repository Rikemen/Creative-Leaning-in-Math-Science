01 置換（Permutation）ってそもそも何？

数学の教科書を開くと「{1, ..., n} から自分自身への全単射」という難しそうな言葉が登場します。 でも、プログラミングや日常の感覚で言えば、置換とはとてもシンプルです。

図1: 3つの席（1, 2, 3）で行われる「完璧な席替え」のルール

置換とは、「誰も消えず、誰もダブらない、メンバーの席替え（シャッフル）のルール」です。

  • 1番の人は、2番の席へ移動する（$1 \to 2$）
  • 2番の人は、3番の席へ移動する（$2 \to 3$）
  • 3番の人は、1番の席へ移動する（$3 \to 1$）

このとき、移動先の席（2, 3, 1）にも 1, 2, 3 の全員がちょうど1回ずつ現れます。 この「誰も漏れず、重複もしない1対1の対応」のことを、数学ではかっこよく「全単射（ぜんたんしゃ / bijection）」と呼んでいるだけなのです。

💡 数学の記号 σ（シグマ）

数学では、この席替えルールのことをギリシャ文字の $\sigma$（シグマ） などの関数で書きます。
「1をルール $\sigma$ に入れると 2 になる」ことを $\sigma(1) = 2$ と表現します。プログラミングの関数 sigma(1) === 2 とまったく同じ感覚です！

02 最大の疑問：「#images」の正体は？（画像じゃないの？）

Permutation.js を開いて一番最初に目に飛び込んでくるのが、このコードです。 

class Permutation {
    #images;

    /** @param {number[]} images - [σ(1), ..., σ(n)]。例: [2, 3, 1] */
    constructor(images) {
        // ...
        this.#images = [...images];
    }
}

Web制作をやっている人なら、「えっ？ image？ 画像ファイル（<img> や JPG/PNG）を扱うの？」と思ってしまいますよね。 いいえ、画像とはまったく関係ありません！

🖼️ Web開発の image

写真やイラストなどの画像データ（JPEG, PNG, SVG）。ブラウザで描画するもの。

🎯 数学用語の「像（image）」

関数に値を入れたときに「写った先（出力結果）」のこと！ $f(x)$ の結果を「$x$ の像」と呼びます。

図2: 入力 1, 2, 3 が写った先の値たち（2, 3, 1）の並びを「images（像の配列）」と呼んでいる

数学では、入力 1 に対する行き先 $\sigma(1) = 2$ のことを「1 の像（image）」と呼びます。
そして、1の像、2の像、3の像……という行き先の数字をずらりと並べた配列だから、複数形の images（像たち）という変数名が付けられているのです！

先頭の「#」って何？

JavaScript（ES2022以降）では、クラスのプロパティの先頭に # を付けると、「プライベートフィールド（非公開変数）」になります。 

const p = new Permutation([2, 3, 1]);

// クラスの外部から直接触ろうとすると……
console.log(p.#images);
// ❌ Uncaught SyntaxError: Private field '#images' must be declared in an enclosing class
// （文法エラーとなり、絶対にアクセスできない！）

もし p.images のように公開されていると、誰かが後から p.images[0] = 999; のように書き換えてしまい、「1〜nの完璧な席替え」という大前提が壊れてしまいます。 それを防ぐため、「この配列は金庫の中に厳重にしまって、外からは直接触らせない」という意思表示が #images の # なのです。

03 クラスの骨格と constructor（安全装置）

インスタンスを生成するときに呼ばれる constructor を見てみましょう。 ここには、不正なデータが入ってきた瞬間にピシッと弾く「防御的プログラミング」が詰まっています。

Permutation.js (抜粋)
constructor(images) {
    // ① 配列でなければ即座にエラー
    if (!Array.isArray(images)) {
        throw new TypeError('置換の対応は配列で指定してください。');
    }
    // ② 要素数が 0（空配列）ならエラー
    if (images.length === 0) {
        throw new RangeError('置換には1個以上の要素が必要です。');
    }

    // ③ 重複（ダブり）がないかを Set で瞬間チェック
    const seen = new Set();
    for (const value of images) {
        Permutation.#validateElement(value, images.length);
        if (seen.has(value)) {
            throw new RangeError('置換の対応先は重複できません。');
        }
        seen.add(value);
    }

    // ④ 防御的コピー：渡された配列をそのまま保持せず、新しい配列として複製する
    this.#images = [...images];
}

注目ポイントを紐解く

📦 Set による重複検知

Set は重複を許さないコレクションです。 seen.has(value) で「この数字はすでに見たか？」を確認し、二重に来たら即座に RangeError を投げます。

🛡️ [...images] の防御的コピー

もし this.#images = images; と書くと、配列の参照（アドレス）が共有されてしまいます。 外側のコードが配列を書き換えても壊れないよう、[...]（スプレッド構文）で完全に別物のコピーを作っています。

⚠️ なぜ for...of を使っているのか？

JavaScriptの配列には、new Array(3) のように作った「穴（未定義要素）」を持つ疎配列があります。 for (const value of images) を使うと、穴がある場所も undefined としてループ内で取り出されるため、次の #validateElement で確実に弾くことができます。

04 内部専用の門番：「static #validateElement」

ファイルの末尾にある小さなメソッドですが、コードの品質を支える要です。

Permutation.js: 145〜152行目
static #validateElement(value, size) {
    if (typeof value !== 'number') {
        throw new TypeError('要素は数値で指定してください。');
    }
    if (!Number.isInteger(value) || value < 1 || value > size) {
        throw new RangeError(`要素は1〜${size}の整数で指定してください。`);
    }
}

この関数の役割は極めてシンプルです。

  1. 数値型（number）であるか？（文字列 "1" や null などを拒否）
  2. 整数であるか？（Number.isInteger により、小数 1.5 や NaN、Infinity を拒否）
  3. 1 から size までの範囲に収まっているか？（0 や 4 などを拒否）

頭に static # が付いているので、「クラスの内部だけで使い回せる共通ユーティリティ」として機能しています。

05 置換を調べる3つの道具（size, apply, toArray）

置換オブジェクトを作ったら、その中身を調べるためのメソッドたちです。 ここには、「数学の1始まり」と「JavaScriptの0始まり」のズレを解消する工夫があります。

Permutation.js: 25〜39行目
/** @returns {number} 次数（読み取り専用） */
get size() {
    return this.#images.length;
}

/** @param {number} i - 1〜n の整数。 @returns {number} σ(i) */
apply(i) {
    Permutation.#validateElement(i, this.size);
    return this.#images[i - 1]; // ← ★ ここに注目！
}

/** @returns {number[]} 対応表のコピー */
toArray() {
    return [...this.#images];
}

1始まりと0始まりの架け橋「i - 1」

数学の世界では、席の番号は通常 1, 2, 3 ... n と数えます。
しかし JavaScript の配列のインデックス（添字）は 0, 1, 2 ... n-1 です。

数学の入力番号 $i$ JavaScript 配列の添字 [i - 1] 保存されている像 #images[i - 1]
1（1番目の人） 0 番目の部屋 2（2番の席へ行く）
2（2番目の人） 1 番目の部屋 3（3番の席へ行く）
3（3番目の人） 2 番目の部屋 1（1番の席へ行く）

apply(i) の中で this.#images[i - 1] としているおかげで、 使う側は sigma.apply(1) と直感的な「1番」を指定するだけで、正しく配列の先頭データを取り出せるようになっています。

💡 get size() って何？

メソッドの前に get を付けると「ゲッター」になります。
普通のメソッドのように p.size() とカッコを付けず、p.size とプロパティのように書くだけで中身を取り出せます。代入（p.size = 5）は禁止されているので、安全な読み取り専用プロパティとして振る舞います。

06 基準を作る（恒等置換 identity）

「誰の席も変えない、そのままの置換」を恒等置換（こうとうちかん / identity permutation）と呼びます。
数字の掛け算でいう「1」のような、すべての基準となる存在です。

Permutation.js: 42〜50行目
static identity(n) {
    if (typeof n !== 'number') {
        throw new TypeError('次数は数値で指定してください。');
    }
    if (!Number.isInteger(n) || n < 1) {
        throw new RangeError('次数は1以上の整数で指定してください。');
    }
    return new Permutation(Array.from({ length: n }, (_, i) => i + 1));
}

魔法のような1行：Array.from({ length: n }, (_, i) => i + 1)

この1行は、初学者の方が一番「何これ？」となりやすいコードです。丁寧に分解してみましょう！

1. { length: n }

「長さ n のダミーオブジェクト」です。これを使うと、要素数 n 個の配列の枠組みを用意できます。

2. (_, i) => i + 1

各要素に何を入れるかを決める関数です。第2引数の i にはインデックス（0, 1, 2...）が入ります。
第1引数の _（アンダースコア）は「この値は使わないよ」というプログラミングの慣習的な記号です。

結果として、もし n = 3 なら、[0 + 1, 1 + 1, 2 + 1]、すなわち [1, 2, 3] という「1→1, 2→2, 3→3」の配列が一発で生成されます。 最後に new Permutation(...) で包んで返すことで、恒等置換のインスタンスが完成します！

07 2つの置換を連続適用（合成 compose）

置換の最も面白い操作が「合成（composition）」です。2つの席替えルールを続けて行います。

Permutation.js: 57〜69行目
compose(other) {
    if (!(other instanceof Permutation)) {
        throw new TypeError('合成相手には置換を指定してください。');
    }
    if (this.size !== other.size) {
        throw new RangeError('合成する置換の次数が一致しません。');
    }
    const result = [];
    for (let i = 1; i <= this.size; i++) {
        // ★ 先に other（右側）を適用し、その結果を this（左側）に渡す
        result.push(this.apply(other.apply(i)));
    }
    return new Permutation(result);
}
🚨 最重要：なぜ「右側」から先に動くのか？

数学でふたつの関数を合成するとき、$\sigma \circ \tau$（シグマ・マル・タウ）と書きます。
これに入力 $i$ を与えると、$\sigma(\tau(i))$ になりますよね。
カッコの内側にある $\tau(i)$ を先に計算して、出てきた値を外側の $\sigma$ に渡すルールになっているからです！

図3: this.apply(other.apply(i)) の流れ（内側から外側へ）

ですから、alpha.compose(beta) と書いたときは、「まず beta をやって、その後に alpha をやる」という順序になります。 一般に、置換の合成は順番を入れ替えると結果が変わります（非可換性）。

08 矢印を逆向きにする（逆置換 inverse）

席替えをしたあと、「やっぱり元の席に戻りたい！」というときのための操作が逆置換（ぎゃくちかん / inverse permutation）です。 記号では $\sigma^{-1}$ と書きます。

Permutation.js: 72〜79行目
inverse() {
    const result = [];
    for (let i = 1; i <= this.size; i++) {
        // σ(i) の行き先を i にする。配列の添字だけ0始まりに変換する。
        result[this.apply(i) - 1] = i;
    }
    return new Permutation(result);
}

パズルのような代入：result[this.apply(i) - 1] = i

ここも一見トリッキーに見えますが、具体例で追うと「なるほど！」と腑に落ちます。 例えば $\sigma = [2, 3, 1]$（1→2, 2→3, 3→1）のときを考えてみましょう。

元の移動 $i \to \text{行き先}$ 逆の移動（元に戻すルール） JavaScriptの代入文
$i=1 \implies \text{行き先 } 2$ 2 の人は 1 へ戻す result[2 - 1] = 1 （添字1番地に 1 を入れる）
$i=2 \implies \text{行き先 } 3$ 3 の人は 2 へ戻す result[3 - 1] = 2 （添字2番地に 2 を入れる）
$i=3 \implies \text{行き先 } 1$ 1 の人は 3 へ戻す result[1 - 1] = 3 （添字0番地に 3 を入れる）

すべて代入し終えると、result は [3, 1, 2] になります！
元の置換と逆置換を合成すると、必ず全員が元の席に戻る恒等置換 [1, 2, 3] になります。

09 ぐるぐる回す（巡回置換 cycle と % 演算子）

「1は3へ、3は2へ、2は1へ」のように、指定した輪の中でぐるぐる巡回し、指定されていない人は動かない置換を巡回置換（じゅんかいちかん / cyclic permutation）と呼び、$(1\ 3\ 2)$ と書きます。

Permutation.js: 87〜108行目 (抜粋)
static cycle(n, elements) {
    // ① まずは全員動かない恒等置換 [1, 2, ..., n] をベースとして用意
    const result = Permutation.identity(n).toArray();
    // ...（入力検証）...

    // ② elements に指定された人たちだけを次の位置へ書き換える
    for (let i = 0; i < elements.length; i++) {
        // 最後の要素は先頭へ戻す（% elements.length で折り返す）
        result[elements[i] - 1] = elements[(i + 1) % elements.length];
    }
    return new Permutation(result);
}
💡 剰余演算子 % によるループの作り方

(i + 1) % elements.length は、プログラミングで輪っか（サーキュラー）構造を作るときの定番テクニックです。
例えば elements = [1, 3, 2]（長さ3）のとき：

  • i = 0 のとき：(0 + 1) % 3 = 1 → 次の要素 elements[1]（3）へ！
  • i = 1 のとき：(1 + 1) % 3 = 2 → 次の要素 elements[2]（2）へ！
  • i = 2 のとき：(2 + 1) % 3 = 0 → 先頭の elements[0]（1）へぐるっと戻る！

10 たった2つだけを交換する（互換 transposition）

置換の中で最もシンプルで強力な部品が、「2人だけを入れ替えて、あとの全員はその場にステイする」という操作です。 これを互換（ごかん / transposition）と呼びます。

Permutation.js: 117〜119行目
static transposition(n, a, b) {
    return Permutation.cycle(n, [a, b]);
}

なんと、コードはたったの1行です！
なぜなら「$a$ と $b$ を入れ替える」とは、「$a \to b$、$b \to a$」という長さ2の巡回置換そのものだからです。 先ほど作った Permutation.cycle に [a, b] を渡すだけで、車輪の再発明をすることなくエレガントに実装されています。

11 あみだくじの交差と偶奇（符号 sign）

線形代数で行列式（determinant）を計算するとき、絶対に必要になるのが置換の「符号（sign）」です。
符号は +1 または -1 のどちらかになります。

Permutation.js: 122〜143行目
sign() {
    let inversions = 0;
    for (let i = 1; i <= this.size; i++) {
        for (let j = i + 1; j <= this.size; j++) {
            // i < j なのに σ(i) > σ(j) となる組が「転倒」
            if (this.apply(i) > this.apply(j)) {
                inversions++;
            }
        }
    }
    return inversions % 2 === 0 ? 1 : -1;
}

isEven() { return this.sign() === 1; }
isOdd()  { return this.sign() === -1; }

転倒（反転）って何？ ＝ あみだくじの交差の数！

「元の順番では $i < j$ と $i$ の方が小さかったのに、移動先では $\sigma(i) > \sigma(j)$ と大小関係がひっくり返ってしまったペア」のことを転倒（反転 / inversion）と呼びます。

図4: あみだくじの線が交差する回数 ＝ 転倒数

例えば $\sigma = [2, 3, 1]$ を調べると：

  • ペア (1, 2)：行き先は $2 < 3$（順調、転倒ではない）
  • ペア (1, 3)：行き先は $2 > 1$（逆転！ 転倒 +1）
  • ペア (2, 3)：行き先は $3 > 1$（逆転！ 転倒 +1）

合計で 転倒数は 2（偶数） です。
転倒数が偶数なら「偶置換（符号 +1）」、奇数なら「奇置換（符号 -1）」となります。

13 理解度チェック！3つの腕試しクイズ

ここまで読んだ知識で解ける、簡単なクイズを用意しました。クリックすると答えと理由が開きます。

Q1. new Permutation([3, 1, 2]).apply(2) の実行結果は何になる？

正解： 1

apply(i) は $i$ 番目の人の移動先を返します。
2番目の人の行き先は、配列 [3, 1, 2] の2番目の数字、すなわち 1 です！

Q2. Permutation.cycle(4, [2, 4, 3]).toArray() の配列はどうなる？

正解： [1, 4, 2, 3]

1〜4のうち、動くのは 2, 4, 3 だけです（$2 \to 4$, $4 \to 3$, $3 \to 2$）。
指定されていない 1 はそのまま動かない（$1 \to 1$）ので、全体として [1, 4, 2, 3] になります。

Q3. new Permutation([3, 2, 1]) の転倒数と符号（sign）は？

正解： 転倒数 3、符号 -1（奇置換）

ペアごとの行き先の大小関係をチェックしてみましょう：

  • (1, 2)：行き先は $3 > 2$（転倒！）
  • (1, 3)：行き先は $3 > 1$（転倒！）
  • (2, 3)：行き先は $2 > 1$（転倒！）

すべてのペアで逆転が起きているため、転倒数は 3 です。
奇数なので $(-1)^3 = -1$、つまり「奇置換」になります。

/** {1, ..., n} から自分自身への全単射を表す。Matrix や p5.js には依存しない。 */
class Permutation {
    #images;

    /** @param {number[]} images - [σ(1), ..., σ(n)]。例: [2, 3, 1] */
    constructor(images) {
        if (!Array.isArray(images)) {
            throw new TypeError('置換の対応は配列で指定してください。');
        }
        if (images.length === 0) {
            throw new RangeError('置換には1個以上の要素が必要です。');
        }
        const seen = new Set();
        // for...of は疎配列の穴も undefined として検証する。
        for (const value of images) {
            Permutation.#validateElement(value, images.length);
            if (seen.has(value)) {
                throw new RangeError('置換の対応先は重複できません。');
            }
            seen.add(value);
        }
        this.#images = [...images];
    }

    /** @returns {number} 次数（読み取り専用） */
    get size() {
        return this.#images.length;
    }

    /** @param {number} i - 1〜n の整数。 @returns {number} σ(i) */
    apply(i) {
        Permutation.#validateElement(i, this.size);
        return this.#images[i - 1];
    }

    /** @returns {number[]} 対応表のコピー */
    toArray() {
        return [...this.#images];
    }

    /** @param {number} n - 正の整数。 @returns {Permutation} 恒等置換 */
    static identity(n) {
        if (typeof n !== 'number') {
            throw new TypeError('次数は数値で指定してください。');
        }
        if (!Number.isInteger(n) || n < 1) {
            throw new RangeError('次数は1以上の整数で指定してください。');
        }
        return new Permutation(Array.from({ length: n }, (_, i) => i + 1));
    }

    /**
     * σ∘τ を返す。右側の τ を先に適用し、元の置換は変更しない。
     * @param {Permutation} other - τ
     * @returns {Permutation}
     */
    compose(other) {
        if (!(other instanceof Permutation)) {
            throw new TypeError('合成相手には置換を指定してください。');
        }
        if (this.size !== other.size) {
            throw new RangeError('合成する置換の次数が一致しません。');
        }
        const result = [];
        for (let i = 1; i <= this.size; i++) {
            result.push(this.apply(other.apply(i)));
        }
        return new Permutation(result);
    }

    /** @returns {Permutation} 元の置換を変更せずに逆置換を返す。 */
    inverse() {
        const result = [];
        for (let i = 1; i <= this.size; i++) {
            // σ(i) の行き先を i にする。配列の添字だけ0始まりに変換する。
            result[this.apply(i) - 1] = i;
        }
        return new Permutation(result);
    }

    /**
     * (a₁ a₂ ... aₖ) を作る。指定外の要素は固定する。
     * @param {number} n - 次数
     * @param {number[]} elements - 巡回する順番（1要素なら恒等置換）
     * @returns {Permutation}
     */
    static cycle(n, elements) {
        const result = Permutation.identity(n).toArray();
        if (!Array.isArray(elements)) {
            throw new TypeError('巡回する要素は配列で指定してください。');
        }
        if (elements.length === 0) {
            throw new RangeError('巡回には1個以上の要素が必要です。');
        }
        const seen = new Set();
        for (const value of elements) {
            Permutation.#validateElement(value, n);
            if (seen.has(value)) {
                throw new RangeError('巡回する要素は重複できません。');
            }
            seen.add(value);
        }
        for (let i = 0; i < elements.length; i++) {
            // 最後の要素は先頭へ戻す。
            result[elements[i] - 1] = elements[(i + 1) % elements.length];
        }
        return new Permutation(result);
    }

    /**
     * 異なる2要素 a, b を交換する互換 (a b) を作る。
     * @param {number} n - 次数
     * @param {number} a
     * @param {number} b
     * @returns {Permutation}
     */
    static transposition(n, a, b) {
        return Permutation.cycle(n, [a, b]);
    }

    /** @returns {number} 転倒数 I に対する符号 (-1)^I（+1 または -1） */
    sign() {
        let inversions = 0;
        for (let i = 1; i <= this.size; i++) {
            for (let j = i + 1; j <= this.size; j++) {
                // i < j なのに σ(i) > σ(j) となる組が「転倒」。
                if (this.apply(i) > this.apply(j)) {
                    inversions++;
                }
            }
        }
        return inversions % 2 === 0 ? 1 : -1;
    }

    /** @returns {boolean} 偶置換か（符号が +1） */
    isEven() {
        return this.sign() === 1;
    }

    /** @returns {boolean} 奇置換か（符号が -1） */
    isOdd() {
        return this.sign() === -1;
    }

    static #validateElement(value, size) {
        if (typeof value !== 'number') {
            throw new TypeError('要素は数値で指定してください。');
        }
        if (!Number.isInteger(value) || value < 1 || value > size) {
            throw new RangeError(`要素は1〜${size}の整数で指定してください。`);
        }
    }
}
